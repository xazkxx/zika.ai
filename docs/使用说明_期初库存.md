# 使用说明：商品期初库存（数字联动版）

> 面向：财务、仓管、负责建账的同事
> 版本：v75（2026-10-20）
> 一句话：**上面那排数字现在能点了，点一下下面的表就跟着筛。**

菜单位置：**库存管理 → 商品期初库存**（以前有人叫它"期初建账"，指的是同一个页面）

---

## 一、这一排数字什么意思

| 卡片 | 含义 |
|---|---|
| **期初行数** | 建了多少行期初（一个"仓库+商品"算一行） |
| **期初总数量** | 所有期初数量加起来 |
| **期初总金额** | 数量 × 期初成本单价，加总 |
| **已发生业务** | 有多少行**在期初之后已经发生过出入库** |

---

## 二、哪两张卡能点

### 1）「期初行数」——点我看全部

点它 = **清空筛选**，下面是全部期初行。
它高亮（蓝底）就说明"你现在看到的就是全部"。

### 2）「已发生业务」——点我只看这些行

点它 = 下面表格**只留下已经发生过出入库的那几行**。

- 卡片会变成高亮，小字提示"已筛选 · 再点取消"；
- 再点一次 = 取消筛选，回到全部；
- 表格标题旁边会显示「筛出 12 / 共 340 项」，右上角出现「**清除筛选**」按钮。

### 为什么"已发生业务"这张卡值得单独点一下？

因为**这些行的期初是"敏感行"**：它们的期初一旦改动，会影响期初之后第一笔出入库的结存起点，历史成本的链条会整体挪动。

> 老会计的说法：期初是账的"零刻度"。零刻度一动，后面所有刻度都跟着动。
>
> 所以：**已经发生出入库的行，原则上不要再改期初数量**。真改错了，走"盘点/调整单"或者红冲，别直接改期初。

（目前只有**行数**和**已发生业务**做成了可点；「总数量」「总金额」没有对应的筛选维度，保持只读展示。）

---

## 三、怎么录入期初

页面上半部分是录入区：

1. **仓库**：选一个；
2. **商品**：支持搜索名称 / SKU / 助记码；
3. **期初数量**：填数字（可以带小数，比如 12.5 米）；
4. **成本单价**：这是算金额的依据，请填准；
5. **备注**：选填；
6. 点「**加入清单**」→ 这一行进到下面的待提交清单；
7. 全部加完 → 点提交保存。

**防呆提醒：**

- **数量、单价都支持小数**。别被输入框的箭头骗了，那是步进按钮，不是限制。
- 同一个仓库 + 同一个商品**只能有一行期初**。重复加会覆盖或报错，先看清单里有没有。
- 「清空全部期初」是**危险操作**，按钮只在有数据时亮，点了会二次确认。**做之前先导出一份**（商品档案 → 导出）。

---

## 四、批量建账的更快办法

如果要建几百个商品的期初，一行行敲太慢：

1. 去「**商品档案**」，右上角「导入」；
2. 下载模板，填好（商品编码、仓库、数量、单价）；
3. 上传，系统批量建账。

> 期初页的空态提示也写了这条路。

## 五、常见问题

**Q：点「已发生业务」后表是空的，是坏了吗？**
A：不是。说明你**还没有任何一行期初发生过出入库**（通常是刚建完账、还没开单）。点「期初行数」卡或「清除筛选」就回来了。

**Q：改了一行期初，为什么库存数量没变？**
A：期初只是"起点"。现存量 = 期初 + 入库 - 出库。改期初会改起点，但如果这一行已经有出入库，系统会按你新的起点重算结存——**建议改完立刻去「库存管理」核对一下**。

**Q：期初总金额和库存看板上的"库存总金额"为什么不一样？**
A：两个口径不同：
- 期初总金额 = 建账时填的**成本单价 × 期初数量**，是"起点值"，永远不变；
- 库存看板的金额 = 现在的数量 × 商品档案当前的采购价，是"此刻值"。
