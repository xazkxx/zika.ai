# 拖拽后"自动展开 + 高亮定位"全局收口（2026-10-21 晚 · 第三轮）

> 用户报障：拖到二级/三级分类后，右下角提示成功、右侧列表也过滤了，但**左侧树没展开也没定位**。
> 本轮把"定位到目标"做成一条**不依赖具体入口**的规则，并推到三类档案。
> 交付版本 **v148 · 20261021-2025**（纯前端，`Ctrl + F5` 即可）。

---

## 一、为什么第一版会漏

第一版只在"拖拽"这一条路上挂了 `revealSignal`，靠一个 **60ms 的固定 setTimeout** 去
`scrollIntoView` + 闪烁。三个薄弱点：

| 薄弱点 | 后果 |
|---|---|
| 固定 60ms 等待 | 接口慢一点 / 树重载慢一点，行还没渲染 → `rowRefs` 拿不到 → **既不滚动也不闪** |
| 只认 `revealSignal` | 从别处把某个分类设为选中（跳转聚焦、搜索命中、代码调用）**不会**展开祖先，树里看不到当前选中项 |
| 树停在搜索过滤态 | 目标不在命中集合里 → 行根本不存在，怎么等都等不到 |

## 二、这轮的改法

**① reveal 改成轮询**：每 50ms 探一次，最多 1.2s，行一出现就滚动+闪烁
（固定延时改成"等到为止"，机器慢也不会漏）。

**② 加一条兜底规则：选中即展开** —— 不再依赖"是拖拽触发的"。

```js
// PartnerTree / ProductCategoryTree 各一份
useEffect(() => {
  if (!选中 || 选中是 ALL/未分类) return;
  const hidden = ancestorsOf(index, 选中).filter(id => 还折叠着);
  if (hidden.length) setExpanded(prev => new Set([...prev, ...hidden]));
}, [选中, index, expanded]);
```

这条把"树里找不到当前选中的那一项"这件事从根上消灭了 —— 不管选中是怎么来的。

**③ 揭示时清掉树的搜索词**：拖完用户想看的是"它进了哪个分类"，不是"我刚才搜的那几个字"。

**④ 推广到三类档案**（用户要求"全局统一"）：

| 档案 | 状态 | 说明 |
|---|---|---|
| 客户 | 已有，本轮加固 | `PartnerTree` |
| 供应商 | **本轮开放** | `PARTNER_DND_KINDS` 加 `'supplier'`，后端接口上一轮就绪 |
| 商品 | **本轮新建** | `ProductCategoryTree` 加落点+揭示；行拖拽走 `application/x-erp-products`；落库 `PATCH /products/batch-category`（**传类别名**，不是 id） |

商品这条不能照抄客户：`products.category` 是**名称字符串**列（历史上为了不迁移 262 个存量
商品才这么定的），所以拖拽时把 `node.name` 交给后端，而不是 `category_id`。

## 五、第二轮：用户回"没发现变化"（v148 · 20261021-2048）

截图复核的结论：**定位本身是生效的** —— 树已展开「中铁一局集团 / 新运工程公司」，
目标「塞拉利昂铁路运营公司」已是选中态（`is-active`），右侧列表过滤到 1 条，
底部提示「已成功移动 1 个客户至「塞拉利昂铁路运营公司」分类」。

"没发现变化"的真实原因有两个，都能解释成"看不见"：

| 问题 | 为什么看不见 | 这轮怎么改 |
|---|---|---|
| 归档的**闪烁只有 900ms、且只有一道 1px 内描边** | 目标节点本来就已展开/已选中时，树没有任何"新东西"出现，闪一下很容易错过 | 1.6 秒、蓝底 + 蓝环三次呼吸；JS 摘 class 的时长同步到 1.6s（否则动画没收尾就被摘掉） |
| **分类列 160px**，全路径必然被省略号截断；表头抓手只在悬停时才显形 | 用户以为"列宽那个功能没做" | 分类列默认 **240px**；表头分隔线**常显**（淡灰 1px，悬停变蓝加粗），一眼能看出"这里能拖" |

实测（`v151_归档闪烁_1.6秒.png`）：三级节点蓝底 + 蓝环、祖先全展开、右表 1 条、提示条正常。

补充口径：**目标本来就可见时，不会产生"跳转"**——树没滚动是正确行为。
判断"有没有生效"看这三样：① 目标行变蓝并呼吸 1.6s；② 祖先全部展开；③ 右侧列表过滤到该分类。
只有目标在视野外时才会看到滚动。
