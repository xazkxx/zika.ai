### 1.3 代码形态（以 `sales_order.py` 为例）

```python
# 改前
from sqlalchemy import DateTime, Float, Integer, String, func
...
total_amount: Mapped[float] = mapped_column(Float, default=0.0, nullable=False)

# 改后
from decimal import Decimal
from sqlalchemy import DateTime, Float, Integer, Numeric, String, func
...
total_amount: Mapped[Decimal] = mapped_column(
    Numeric(14, 2), default=0, nullable=False, comment="价税合计（定点小数，勿用 float）"
)
```

⚠️ 三个容易写错的地方：

1. **`float` → `Decimal` 的注解要一起改**。注解不影响 SQLAlchemy 建表（类型由 `Numeric` 决定），
   但注解不改，后来的人照着 `Mapped[float]` 写 `Decimal * 0.13` 就会崩。
2. **`default=0.0` 要改 `default=0`**（int）。`0.0` 也能用，但会让"这列是定点数"这件事看起来不像真的。
3. **`Numeric(asdecimal=True)` 是默认值**，不要显式写 `asdecimal=False` —— 那等于把 `Decimal` 又变回 `float`。

### 关于"前端会收到什么"（很重要，别被 JSON 骗了）

浏览器 `JSON.parse` 之后又变回 `float`。

这正是清单 D 存在的原因 —— 前端必须自己"用完即舍"，不能拿浮点数一路累加下去。

## 3. 清单 C：后端"传染面"（改完 Model 会立刻崩的地方）

三个固定改法：

| 崩法 | 现象 | 改法 |
|---|---|---|
| `Decimal * 0.13` | `TypeError: unsupported operand type(s)` | 常量改成 `Decimal("0.13")`，或先 `Decimal(str(x))` |
| `sum(rows, 0.0)` | 第一个元素就 `TypeError` | `sum(rows, Decimal("0.00"))` |
| `round(dec, 2)` | 能跑，但用银行家舍入（`2.675 → 2.67`） | 要"四舍五入"就写 `dec.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)` |

它们现在写的是 `float(item.total_amount or 0)` —— **不用改**，`float(Decimal)` 是合法的，
而且显式转 float 能让 JSON 序列化行为保持一致。这一层丢的是"第 3 位以后"，不影响钱。

## 4. 清单 D：前端（新增 `frontend/src/lib/money.js`）

你说的是"toFixed(2) 后再转 Number"，方向对，但**不能直接用 `toFixed`**：
`(1.005).toFixed(2)` 在 JS 里是 `"1.00"`（因为 `1.005` 实际存的是 `1.00499999999999989`）。
正确姿势是先"挪小数点"再取整：

```js
// frontend/src/lib/money.js
/**
 * 金额安全计算 —— 全站唯一入口。
 *
 * 为什么不能直接用 toFixed(2)：
 *   (1.005).toFixed(2) === '1.00'（浮点里 1.005 其实是 1.00499999999999989），
 *   而业务上这一分钱必须进位。Math.round(n * 100) 同样错：
 *   Math.round(1.005 * 100) === 100（因为 1.005*100 是 100.49999999999999）。
 *   唯一稳的做法是把小数点"挪"到数字串里：Number('1.005e2') === 100.5 → round → 101。
 */
const EPS = 10; // 先放大 10 倍消掉二进制噪声

export function round2(value) {
  const n = Number(value);
  if (!Number.isFinite(n)) return 0;
  // 先消噪声（1.00499999999999989 → 1.005），再挪小数点取整，最后挪回来
  const cleaned = Number(n.toFixed(10));
  return Math.round(Number(`${cleaned}e2`)) / 100;
}

/** 单价要 4 位：73.901 不能变 73.9 */
export function round4(value) {
  const n = Number(value);
  if (!Number.isFinite(n)) return 0;
  const cleaned = Number(n.toFixed(10));
  return Math.round(Number(`${cleaned}e4`)) / 1e4;
}

/** 行金额 = 单价 × 数量（单价 4 位 → 结果 2 位） */
export function lineAmount(unitPrice, quantity) {
  return round2(round4(unitPrice) * Number(quantity || 0));
}

/** 合计 = 逐行金额相加（绝不"合计单价 × 合计数量"） */
export function sumAmounts(list, pick = (row) => row.amount) {
  const total = (list || []).reduce((acc, row) => acc + round2(pick(row)), 0);
  return round2(total);
}

/** 展示：千分位 + 两位小数；负数带负号不吞掉 */
export function money(value) {
  return round2(value).toLocaleString('zh-CN', {
    minimumFractionDigits: 2,
    maximumFractionDigits: 2,
  });
}
```
