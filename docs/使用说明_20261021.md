# ERP 使用说明（2026-10-21 · v151）

> 面向日常使用者（录单、档案、对账、打印）。技术部署/打包见 `docs/使用说明_桌面版启动与打包.md`。
> 版本号看左下角：**v151 · 20261021-2119**。页面显示旧版本就按 `Ctrl + F5` 强刷。

## 一、启动与登录

| 场景 | 做法 |
|---|---|
| 本机使用 | 双击 `启动ERP.vbs`（无窗口）→ 浏览器自动打开 `http://127.0.0.1:8010` |
| 局域网其它电脑 | 先跑一次 `配置局域网访问.bat`，再用 `http://<本机IP>:8010` |
| 打不开 / 白屏 | 先 `Ctrl + Shift + R` 强刷；仍是白屏看 exe 同目录 `erp_error.log` |
| 后台在跑但没有窗口 | 任务管理器结束 `ERP管理系统.exe` 或 `pythonw.exe` |

默认账号 `admin`，密码在交付时单独告知。**登录失效**（改过密码/换电脑）→ 右上角退出重登。

## 三、客户 / 供应商档案：拖拽归档（本轮重点）

左侧是分类树，右侧是档案列表。

| 想做的事 | 操作 |
|---|---|
| 把客户归到某个分类 | **直接把右侧那一行拖到左侧分类节点上**松开 |
| 一次归一批 | 先勾选多行，再拖其中任意一行（勾了几行就移几行） |
| 取消分类 | 把行拖到「未分类」节点 |
| 看某个分类下有哪些客户 | **展开分类**（点左边小三角）→ 该分类下的客户会像文件一样平铺列出 |
| 从分类里挑几个换到别处 | 展开分类 → 直接拖那些客户叶子到目标分类 |
| 只看某一条 | 点分类里的客户叶子，右侧列表会按这个名字定位 |

**手风琴**：展开一个一级分类时，同一层的其它分类会**自动收起**（"国家电网"和"中铁一局"不会同时摊开）。

**找不到客户了？** 分类展开后最多平铺 50 条，超过会显示「还有 N 个客户…」，用右侧搜索框找人。

> 编辑弹窗里的「所属分类」下拉仍然保留 —— 需要精确改某一个时用它。

## 四、表格列宽：拖动调整

客户 / 供应商 / 商品三张表：

- 表头之间有**淡灰分隔线**，鼠标移上去变蓝、光标变成左右箭头 → **按住拖**即可调宽
- 调完自动记住（换电脑前先把浏览器数据迁走，或重调一次）
- **双击**分隔线 = 这一列恢复默认宽度
- 拖宽后表格会出现横向滚动条，不会把内容压扁

长文本（客户名、分类全路径）默认显示不下时用**鼠标悬停**看完整内容。

## 五、日常录单（销售出库）

1. 销售管理 → 开单管理 → 「新增」
2. 选客户（可直接输名字搜索）、选仓库、加商品行（数量/单价/单位）
3. 保存 = 生成**草稿**；点「审核」才真正出库并生成应收
4. 草稿可改可删；已审核只能「反审核」或「作废」

**完结条件**：出库单必须**钱票两清**（已收款、已开票）才能完结，否则会提示 `not_settled`。

退货走「销售退货」：反审核只改状态不动账；作废走专门的「作废」按钮（撤库存 + 撤应收 + 留痕）。

## 七、常见问题

**Q：拖拽后左侧树没反应？**
先确认版本号是 v151 及以上。目标分类会**闪一下蓝框**（1.6 秒）并自动展开祖先；如果目标本来就在视野里，树不会滚动（这是对的）。

**Q：拖完右侧列表是空的？**
已修（v151）：拖完会自动切到目标分类并清掉旧勾选。若仍为空，看搜索框里有没有残留关键词。

**Q：分类树里客户名字被截断？**
悬停看全名；或点客户叶子把右侧列表定位过去。

**Q：导出 Excel 少了列？**
「导出 Excel」弹窗里勾选需要的列，导出的是**当前筛选结果**。

**Q：打印模板页脚不对？**
优先级：打印模板 > 系统参数 `print.footer_text` > 默认页码。在系统设置 → 打印模板里改。

## 九、打包发版（pyinstaller + robocopy）

```bat
:: 0) 先关掉正在运行的 ERP（dist 被占用会打包失败）
taskkill /F /IM "ERP管理系统.exe"

cd /d E:\AI\ERP软件

:: 1) 前端构建（后端会把这个目录打进包里）
cd frontend && npm run build && cd ..

:: 2) 打包（正式包，无控制台窗口；要排查启动问题用 set ERP_CONSOLE=1 再打一次）
.venv\Scripts\pyinstaller.exe --noconfirm erp.spec

:: 3) 附件目录不打包，随包复制（换机器也要带着它）
robocopy "data" "dist\ERP管理系统\data" /E

:: 4) 自检：双击 dist\ERP管理系统\ERP管理系统.exe，右下角/左上看版本号
```

产物：`dist\ERP管理系统\`（**整个文件夹一起发**，不能只拷 exe）。
`data/` 是运行期附件（合同/发票/客户归档原件），换机器必须一起搬。
