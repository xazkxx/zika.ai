# 使用说明：导入导出已搬到各档案页

> 版本 v72 · 2026-10-20
> 一句话：左侧的「导入导出」菜单没了，**导入/导出按钮现在就在每个档案页的右上角**。

---

## 1. 为什么改

以前左侧有一个单独的「导入导出」菜单。点进去是个孤岛：
你在「客户档案」里想导客户，得先离开这一页，跑到另一个菜单，再从下拉里选"客户档案"，
选错了才发现导出来的是供应商。

现在不用了。**你在哪个页面，导的就是哪类档案。**

---

## 2. 五个页面都有

| 页面 | 右上角按钮 |
|---|---|
| 基础资料 → 客户档案 | 导入 / 导出 Excel |
| 基础资料 → 供应商档案 | 导入 / 导出 Excel |
| 基础资料 → 商品档案 | 导入 / 导出 Excel |
| 基础资料 → 仓库档案 | 导入 / 导出 Excel |
| 基础资料 → 员工档案 | 导入 / 导出 Excel |

---

## 3. 导出：先勾列，再下载

1. 点右上角「导出 Excel」；
2. 弹出「勾选要写进 Excel 的列」，默认勾好常用六列；
3. 上面会写清楚「共 N 行数据」，导出前你就知道这份表有多大；
4. 按需勾选/取消，或点「全选」「恢复默认」；
5. 点确认才开始下载。

> **注意**：至少要勾一列。一列都不勾时底下会红字提示「至少要勾一列才能导出」，
> 因为导出一个只有表头的空文件等于给了你一个坏文件。

> 如果你在左边只选了一个分类，导出的是**这个分类**；没选分类则导出**全部**——
> 弹窗里会有一行提示告诉你这次的范围，别导出错了才发现。

---

## 4. 导入：三步，中间一定让你先看清

### 第 1 步：下载模板

点「下载导入模板」。模板里第 3 行是示例（**不会被导入**），
**请从第 4 行开始填**。

编码 / 型号这类"用来认人"的列不要留空——
留空会被系统当成一条**新记录**，于是你会得到两个一模一样的客户。

### 第 2 步：选文件，先预检

点「选择文件」，选你填好的 Excel。

这时系统**不会**写库，只会告诉你：

- 会新增几条
- 会更新几条
- 会跳过几条（比如内容完全没变的）
- 失败几条（附具体原因，指到第几行第几列）

### 第 3 步：看清了再确认

预检结果没问题，再点「确认导入」，这时候才真正写进系统。

> **为什么要多这一步**：Excel 导入最常见的事故是"列错位了还点了导入"，
> 结果几百条脏数据进库，半夜清数据。多一次确认，少一次事故。
> 有失败项时，「确认导入」旁边会显示失败条数，你可以先取消回去改文件。

导入成功后列表会自动刷新，你不用手动刷新页面。

---

## 5. 防呆提示

| 情况 | 系统怎么做 |
|---|---|
| 选的文件不是 Excel | 提示格式不对，不预检 |
| 表头和模板对不上 | 预检阶段报错，指出缺少哪一列 |
| 某一行的数量/金额不是数字 | 预检列进"失败"，指明第几行 |
| 预检时按 Esc 关弹窗 | 可以关，反正没写库 |
| 正在下载/预检/写库时按 Esc | 关不掉（请求已发出，关掉你就看不到结果） |
| 写库中途出错 | 报错并说明已写入/未写入，不会假装成功 |

## 6. 常见疑问

**Q：左侧那个「导入导出」菜单去哪了？**
A：下架了。功能全部搬到各档案页右上角。如果你以前的角色权限里勾过它，
那个勾选项也会一起消失，不影响其他权限。

**Q：我能在「商品档案」里导客户吗？**
A：不能，也不需要。每个页面的导入按钮只导本页那一类档案——
这正是改版的目的：不用再选一次"我要导什么"。

**Q：模板能改吗？**
A：能。模板是标准 Excel 文件，你可以加自己的列，但**原有的表头名字不能改**，
否则系统认不出那一列。加在最后的自定义列会被忽略（不会报错）。

**Q：导入会覆盖我手工改过的数据吗？**
A：按编码/型号匹配。匹配到已有记录就**更新**（不是删除重建），匹配不到才新增。
预检里"更新 N 条"就是这些。
