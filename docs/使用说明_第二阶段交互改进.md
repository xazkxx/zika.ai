# 使用说明：单子怎么改、对账单怎么出、报表怎么看（第二阶段）

> 这一版改了六个地方，都是日常最常点的动作。看一遍大约 5 分钟，能省掉以后一堆"点错了怎么办"。

---

## 一、单子点错了，现在能改（销售退货 / 报价单 / 购销合同 / 采购入库）

### 为什么要分"草稿"和"已生效"

系统里一张单子只有两种活法：

- **草稿** —— 只是把数字先记下来，**仓库没动、钱没动**。随便改、随便删，改一百遍账上也不会多一分钱。
- **已生效**（已退货 / 已报价 / 已签订 / 已提交）—— 这张单已经真的动过仓库或者账本了。

所以规矩只有一条：**想改已经生效的单子，先「反审核」把它退回草稿，改完再点生效。**

### 销售退货：怎么存草稿、怎么改、怎么反审核

1. 左边表单填客户、仓库、商品、数量、单价。
2. 底下有两个按钮：
   - **保存并退货** —— 立刻把货收进仓库、同时把客户的应收冲掉。急单用这个。
   - **存为草稿** —— 只把单子存下来，仓库和账本都不动。**拿不准的时候用这个。**
3. 列表里点 **详情**，能看到这张单的全部明细、金额大写、状态。
4. 草稿状态下，行尾有 **编辑**：点它，左边表单会把这张单的内容整套带出来，改完点「保存并退货」或再存草稿。
5. 「已退货」的单子，行尾是 **反审核**：点一下退回草稿。**这一步会把之前加进去的库存和冲掉的应收一起撤回**，单据等于回到没发生过的样子，然后你就能编辑了。

> 防呆：反审核不是"改个标签"。它真的会撤库存、撤应收 —— 如果你已经按这张退货单开了发票或退了钱，先处理那些，再来反审核。

### 报价单

- 草稿可以 **编辑**（左边表单载入原值，改完点「保存修改」）。
- 「已报价」可以 **反审核** 退回草稿。报价单本来就不动库存、不动钱，所以反审核没有副作用，纯改状态。

### 购销合同

- 点一行能看详情；**草稿**在详情里可以直接「编辑草稿」，表单会整套带出来，改完点「保存合同修改」。
- 「已签订 / 执行中」可以 **反审核** 退回草稿。
- **已经生成过单据的合同不能被反审核**（按钮是灰的）—— 因为采购/销售单要能追到合同，合同一退回去，单据的来源就断了。
- 编辑草稿时**不能改合同类型**（销售↔采购）。要换类型请新建一张：换了类型，对方单位是客户还是供应商都变了，改着改着很容易把客户 ID 填进供应商栏。

### 采购入库单

列表行尾新增 **详情**，点开能看到供应商、仓库、日期、审核状态、付款情况、明细表，也能直接打印或反审核。

## 二、对账单：先看，挑，再生成（三步）

以前点一个按钮就直接出一张单，出完才发现有一行不该算进来，只能删了重来。现在分三步：

1. **选往来单位和账期**（比如客户「华邦建设」，2026-01-01 ~ 2026-12-31）。
2. 点 **搜索预览** —— 系统只把这一期的合同 / 发票 / 收付款**列出来给你看**，**这时候还没有生成任何单据**，库里干干净净。
3. 明细出来以后，默认全部打勾。**不想写进对账单的行，把勾去掉。**
4. 点 **生成对账单（N 行）** —— 只有这时候才真的建单，而且只写你勾的那几行。
5. 生成之后，页面上方会出现一条绿色的：
   - **下载 / 打印 PDF**（盖章发给对方）
   - **下载 Excel**（自己核）
   - **下载 Word**（要改措辞时用）

> 防呆：预览页上那行「本单已勾选 X / Y 行」，未勾的行保存时**不会写入**，不是"置灰"。少勾了会真的少一行，生成前多看一眼这行数字。

> 老的「直接生成草稿」还留着（在按钮右边的小字），它会把这一期**全部**记录一次建成单。熟手图快可以用，但拼的是"你先确认过这一期没有脏数据"。

## 三、财务流水：只填收/付 + 金额

以前要填「客户 ID」「供应商 ID」—— 那是一串数字，谁记得住。

现在：

1. 类型选 **收（收款/收入）** 或 **付（付款/支出）**。
2. 填金额。
3. 写一句备注（例：收华邦公司货款）。
4. 点 **确认保存**。

就完了。货币和关联订单 ID 收进了「更多（可选）」，一般不用碰。

> 想让这笔钱挂到某个客户/供应商名下，**不要在财务流水页填**：去销售单 / 采购单上做「收付款登记」，那里会自动带出往来单位，应收应付才算得准。

## 四、报表的日期：下拉 + 快捷按钮

报表中心右上角原来只有两个日期框，每次都要点日历翻半天。现在：

- **年份**下拉 + **月份**下拉（月份里有「全年」）
- 三个快捷按钮：**本月** / **上月** / **今年** —— 点一下日期范围就填好了，再点「查询」
- 需要精确到某几天（比如 3 月 26 日到 4 月 5 日这种月末结算），点开 **自定义**，里面还是原来那两个日期框

> 防呆：快捷按钮只负责"把日期填好"，不会自动帮你查。填完记得点「查询」，否则屏幕上还是上一次的结果。

---

## 五、导出客户/供应商：先挑列，再下载

以前点导出直接就给一个 Excel，里面总有一半列是你不用的。

现在点 **导出 Excel**：

1. 弹出列清单（客户 18 列 / 供应商 15 列），**默认勾好常用 6 列**：编码、名称、联系人、电话、税号、开户行。
2. 要什么勾什么。上面「已选 6 / 18 列」会跟着变。
3. 点 **导出 Excel** 才下载。

- 一列都不勾，「导出」按钮是灰的（导出个只有空行的文件没意义）。
- 「全选 / 全部取消 / 恢复默认」三个小按钮在列表上方。
- **左边分类没选的话，导出的是全部档案**，弹窗里会有一条黄字提醒你，别以为是只导了某一个分类。

## 六、多了一个「← 返回」

页面标题左边出现 **← 返回**，就说明你是从另一个页面点进来的（比如从客户档案点到了单据）。点一下回上一个页面。

它是按你去过的顺序退回的，**最多记 20 层**。刚进系统、还没走动过的时候不会出现这个按钮。

---

## 七、这一版之后仍然要注意的两件事

1. **反审核要慎用**：它会把已经记过的库存和应收一起撤回。已经开票、已经收付款的单子，先说清账务关系再反审核。
2. **草稿不是"暂存"**：草稿是真的存进数据库了，别人也能在列表里看到（状态写着"草稿"）。不想让人看见，请删掉，别指望它自己消失。
