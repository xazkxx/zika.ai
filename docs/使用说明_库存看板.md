# 使用说明：库存管理（看板版）

> 面向：仓管、采购、老板
> 版本：v75（2026-10-20）
> 一句话：**以前是一张几千行的长表，现在先看"几张卡片"，想细看哪一块就点它。**

---

## 一、这个页面变了什么

| | 以前 | 现在 |
|---|---|---|
| 打开页面第一眼 | 一张大表格，几千行往里滚 | 顶部 3 个数字 + 下方一堆汇总卡片 |
| 想知道"A 仓库压了多少货" | 先按仓库筛选，再自己加行 | 卡片上直接写着数量、金额、行数 |
| 想看某个仓库的明细 | 筛选 → 翻表格 | **点那张卡片**，下面的明细表只显示这个仓库 |
| 手工出入库 | 表格上方一个常年挂着的大表单，占掉半屏 | 右上角「+ 手工出入库」→ 右侧滑出一个抽屉 |

菜单位置没变：**库存管理 → 库存管理**。

---

## 二、顶部三个数字怎么用

打开页面最上面一排，是三张**能点的卡片**：

| 卡片 | 显示什么 | 点它会发生什么 |
|---|---|---|
| **总库存量** | 所有仓库加起来还有多少件；下面小字是"共 N 行" | 清掉所有筛选，回到全量视图 |
| **库存总金额（成本）** | 现在的货值多少钱；旁边会有提示 | 清掉筛选，并弹一条提示说明**这个数字是怎么算的** |
| **缺货** | 有多少行已经是负库存；小字还带"低库存 X / 积压 Y" | **只看缺货行**；再点一次 = 取消筛选 |

> **金额是怎么算的？**
> 数量 × **商品档案里填的采购价**。它不含运费、不含税费，所以是"成本参考值"，不是"能卖多少钱"。
> 想要精确成本，请在商品档案里把采购价维护准。

卡片的三个状态提示：

- **缺货** = 库存小于 0（卖超了、出库比入库多）
- **低库存** = 低于商品档案里设的安全库存（该补货了）
- **积压** = 高于安全库存的 3 倍（占资金了）

## 三、按仓库 / 按分类 / 按状态：三种看法

三张数字下面有一排按钮：**按仓库｜按分类｜按状态**。

- **按仓库**：一个仓库一张卡片。想盘 A 仓就点 A 仓。
- **按分类**：一个商品分类一张卡片（来自「商品档案」里的分类）。看哪类货最占钱。
- **按状态**：一张卡片 = 一种状态（缺货 / 低库存 / 积压 / 正常）。

切换后会重新画一遍卡片，明细同时回到"全部"。

**卡片是按紧急程度自动排序的**：缺货的排最前，然后低库存、积压、正常；同一档里金额大的靠前。所以**你每天打开第一眼看到的第一张卡，就是最该处理的那一张。**

## 四、下钻：点卡片看明细

1. 点任意一张卡片（比如「一号仓」）；
2. 下方表格标题从「现存量明细」变成「**明细 · 一号仓**」；
3. 表格只显示这个仓库的行，右上角显示"共 X 行"；
4. 想回来：点标题旁边的「**← 返回看板**」，或者**再点一次刚才那张卡片**（卡片会取消高亮）。

> 蓝色边框 = 这张卡片正在被看。

**下钻和"只看缺货"可以叠一起用**：先点「缺货」卡，再点「一号仓」卡，看到的就是"一号仓里的缺货行"。

## 五、搜索框（原来的筛选没丢）

卡片右侧还有搜索框：**按商品名称 / SKU / 仓库搜索**。

- 输入后，卡片和明细会同时按关键词重算；
- 旁边的「重置」一把清掉：关键词、选中的卡片、缺货筛选，全部回到初始状态。

**筛选不会互相打架**：搜索词 + 卡片下钻 + 缺货开关三者是"同时成立"，不是谁覆盖谁。

---

## 六、手工出入库（移到了右侧抽屉）

右上角「**+ 手工出入库**」→ 右侧滑出一个抽屉：

1. 选仓库、选商品（可以搜名称/SKU/助记码）；
2. 选方向（入库 / 出库）、填数量；
3. 填备注（选填）；
4. 点抽屉底部的「**保存**」。

**防呆提醒：**

- 数量可以填小数（比如 73.9 米），不要只填整数；
- 抽屉没保存就按 `Esc` 或者点右边空白处 → 会直接关掉，**已填的内容不会保存**；
- 保存过程中按钮是灰的，这时按 `Esc` 也关不掉（防止重复提交）；
- 抽屉关掉后如果后端报错（比如"库存不足"），提示会出现在**页面顶部**，不在抽屉里，注意看上面那条横幅。

## 七、常见问题

**Q：卡片上的数量和下面明细自己加一遍对不上？**
A：卡片的"数量"是把同组所有行**求和**，明细表可能有分页。先把筛选清掉再看。

**Q：为什么有个卡片叫"未分类"？**
A：商品档案里没填分类，或者这个商品已经被删掉了。金额不会凭空消失，会被归到「未分类」里，方便你去找。

**Q：缺货数是 0，但我知道有商品卖超了？**
A：缺货判的是**负数库存**。如果出库单被作废/删除了，库存会回正，缺货数就跟着变了。

**Q：想让"缺货"数字变小怎么办？**
A：补货（采购入库）→ 数量回正 → 缺货 -1。或者去「出库单」里查是不是多出库了。
