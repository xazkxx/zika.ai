# 使用说明：页面出错了怎么办（错误兜底与白屏修复）

> 版本 v72 · 2026-10-20
> 一句话：**以后某一块页面画不出来时，你会看到一张说明卡片，而不是整个屏幕变白。**

---

## 1. 这次修的是什么

你在供应商档案里点「中铁一局集团」，整个页面直接白屏，连个报错都没有。
白屏是最难查的现象：**没有提示，你只能猜是网络断了、还是系统坏了。**

真正的原因在代码里（不是那条数据有问题）：
供应商列表的"选了几条 / 要导出哪些"这段逻辑，用到了一个"还没轮到它初始化"的变量。
浏览器遇到这种情况会直接抛错，React 一抛错就把整棵界面树卸掉——
于是你看到一片白。

这段逻辑已经挪到正确的位置，问题消失。

---

## 2. 现在的兜底：出错了会告诉你

万一以后还有别的地方出错，你不会再看到白屏。会出现一张卡片：

```
!
这块页面出错了，没有正常显示

你的数据没有被改动，只是这一块内容没能画出来。
可以点下面的「重新加载这一块」试试；如果反复出错，
请把错误信息复制给管理员。

  <具体的错误信息，一行>

▸ 查看技术细节（给开发 / 客服看）

[重新加载这一块]  [复制错误信息]  [刷新整个页面]
```

重点是这几句：

- **你的数据没有被改动**——只是画不出来，不是数据坏了；
- 有一行**具体的错误信息**，可以直接念给管理员听；
- 有**复制错误信息**按钮，复制的是完整技术细节（含在哪一行出错），
  发给管理员比"白屏了"有用一百倍。

---

## 3. 出错时你该按什么顺序点

1. **先点「重新加载这一块」** —— 大多数临时性问题（比如某个请求刚好超时）这一步就好；
2. 还不行，换到别的页面再切回来（相当于重试一次）；
3. 还不行，点「刷新整个页面」；
4. 一直不行，点「复制错误信息」，把内容发给管理员。

> **千万不要**因为白屏就重启电脑、重装软件、或者删数据。
> 卡片上那句"你的数据没有被改动"是认真的：界面崩了不影响库里已经存好的东西。

---

## 4. 一处出错，不会拖垮整个系统

以前是"一处崩、全屏白"。现在分两层兜底：

- **页面级**：出错只影响当前这一页，左侧菜单、顶部、其他页面照常能用，
  你切到别的菜单它会自动恢复；
- **整机级**：万一连最外层都出错，也还是给你一张卡片，告诉你复制什么给管理员。

---

## 5. 常见疑问

**Q：看到卡片是不是说明我的数据丢了？**
A：不是。卡片只管"画界面"，不碰数据。你之前保存的内容都在库里。

**Q：我点了"重新加载这一块"，勾选的东西没了。**
A：正常。重新加载等于把这一块重新画一遍，界面上的临时勾选会清空。
如果你勾了很多行准备批量操作，出错前**先完成操作**比较稳妥。

**Q：卡片里那行英文我看不懂。**
A：不用看懂。点「复制错误信息」整个发给管理员就行，
里面有出错位置，比描述"我点了个按钮然后就白了"有用得多。

**Q：为什么有时候切到别的页面就好了？**
A：因为出错的只是"那一块"。切走再切回来 = 重新渲染一次，很多一次性错误就过去了。
