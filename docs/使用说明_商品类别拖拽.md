# 商品类别树 · 拖拽调整层级与顺序（使用说明）

> 适用版本：v86 及以后（2026-10-20）
> 入口：左侧菜单「基础资料 → 商品档案」，左侧「商品类别」面板

---

## 一、这次新增了什么

原来商品类别只能靠「+子类 / 改 / 删」三个小按钮维护 —— 想调个顺序、把某个子类
挪到另一个大类下面，只能删掉重建。现在**可以直接用鼠标拖**：

| 你说的操作 | 现在怎么做 |
| --- | --- |
| 把「劳保鞋」拖到「办公家具」上面 | 按住行尾的六个点，往下/往上拖到目标行的**上沿**松手 |
| 把「劳保鞋」拖到「办公家具」下面 | 拖到目标行的**下沿**松手 |
| 把「劳保鞋」变成「员工福利」的子类 | 拖到目标行的**正中间**松手 |
| 把一个子类拖成**大类**（顶级） | 拖到列表最下面的虚线框「拖到这里 → 移到顶级」松手 |

---

## 二、具体怎么拖（三步）

1. **找到抓手**：鼠标移到任意一个类别行上，行尾会出现一个**六个小点**的图标（⋮⋮）。
   它就是拖拽手柄。
2. **按住它，不要松手**，往目标位置移动。屏幕上会出现一个深色小标签跟着鼠标走，
   告诉你"现在正在拖哪个类别"。
3. **看高亮，确认落点**，然后松手：

   | 你看到的画面 | 松手的结果 |
   | --- | --- |
   | 目标行**上面**多出一条**蓝色横线** | 插到这一行前面（同一层级） |
   | 目标行**下面**多出一条**蓝色横线** | 插到这一行后面（同一层级） |
   | 目标行**整行蓝框 + 浅蓝底** | 变成这一行的**子类**（往下挪一层） |
   | 目标行**整行红框** | ❌ 不允许，松手也不会动 |
   | 最下面虚线框变成蓝底 | 移到顶级（变成大类） |

松手之后列表会闪一下（正在保存），1 秒内自动变成新位置。**不需要点保存**。

---

## 三、为什么有些地方拖不进去（这些限制都是有原因的）

### 1. 「不能把一个大类拖到它自己的子类下面」

把「办公家具」拖到「办公椅」下面会发生什么？——「办公家具」变成「办公椅」的子类，
而「办公椅」本来就在「办公家具」里面。两条路绕成一个圈，**这个大类连同它下面所有
子类会从屏幕上彻底消失**，而且再也找不回来（只能找技术改数据库）。

所以拖到这种位置时，目标行会**整行变红**，光标变成禁止符号，松手也不会有任何反应。

### 2. 「同一个上级下不能有两个同名类别」

商品档案里，商品的"所属类别"存的是**类别名字**（不是编号）。如果同一个上级下有两
个都叫「劳保鞋」的类别，系统就分不清某个商品到底属于哪一个 —— 报表、筛选、批量
移动全都会出错。

所以拖过去如果撞名，会弹一句提示「同一上级下已有同名类别」，位置不变。
**解决办法**：先把其中一个改名（点行尾的「改」），再拖。

### 3. 「全部商品 / 未分类」这两行拖不动

它们不是真实的类别节点，是统计用的固定入口（一个代表"全部"，一个代表"没归类
的商品"）。所以这两行没有抓手，拖不了 —— 这不是坏了。

---

## 四、拖完以后右侧商品列表会不会变

**不会。** 拖拽只改类别树本身的两个属性：`属于哪个上级` 和 `在兄弟里排第几`。

- 商品还是属于原来那个类别，**一个商品都没被移动**
- 右侧列表里每个类别后面的数字（商品数）**一个都不会变**
- 「全部商品」的总数也不会变

如果拖完发现右边数据看着"不对"，那是上一轮的列表联动问题，不是拖拽改坏了数据。

## 五、常见疑问

**Q：拖到一半后悔了怎么办？**
按 `Esc`，或者把鼠标拖回原位置松手 —— 只要松手时没有蓝线/蓝框/虚线框高亮，
就等于什么都没发生，不会发请求。

**Q：中间那个"圆点"是什么？**
拖动时鼠标旁边跟着的深色小标签，显示"正在拖的类别名"和"松手会做什么"
（如「移入『办公家具』」「插到这一行前面」）。触屏上手指会挡住落点，全靠它确认。

**Q：手机上能拖吗？**
能。手机上没有"移上去出现手柄"这回事，所以**抓手的六个点会常驻显示**。
按住它直接拖即可（按在别处会变成滚动列表，这是故意的 —— 否则树长的时候滚不动）。

**Q：拖完发现位置没变？**
三种可能：
1. 落点是红色的（拖进了自己的子类）→ 本来就不允许；
2. 弹了「同一上级下已有同名类别」→ 先改名再拖；
3. 松手时没有高亮（手抖移出了行）→ 再拖一次。

**Q：为什么拖完要等一下才变位置？**
松手后是**真的去服务器保存**了，保存完重新读一遍（这是保证你看到的位置和别人
看到的完全一致的做法）。网络慢的时候这 1 秒会长一点。

---

## 六、升级后第一次打开请注意

浏览器可能缓存着旧版本。**按一次 `Ctrl + Shift + R` 强制刷新**，
否则左侧树还是旧样子（没有抓手、拖不动）。

左下角版本号应该显示 **v86** 或更高。
