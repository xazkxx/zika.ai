# 使用说明：生产单 与 BOM 清单（抽屉版）

> 面向：车间主管、生产计划、工艺员
> 版本：v75（2026-10-20）
> 一句话：**新增的地方从"页面左边的大表单"换成了"右上角的「+ 新增」→ 右侧滑出"。**

---

## 一、生产单

菜单：**生产管理 → 生产单**

### 页面现在长什么样

从上到下三块：

1. **生产流程状态** —— 每张单子一条横向进度条（工序走到第几步，一眼看出来）；
2. **工单 / 排程 / 产线看板** —— 三个小格：工单执行、排程、产线负荷；
3. **生产单列表** —— 最近的 8 条（超过 8 条会写"共 N 条，仅显示最近 8 条"）。

> 以前最上面那一大坨"新增生产单"表单没了，**页面一打开就能看到流程状态**，这是本次改动的核心。

### 怎么新增一张生产单

1. 点「生产流程状态」标题右侧的「**+ 新增**」；
2. 右侧滑出抽屉，填 6 项：

| 字段 | 必填 | 说明 |
|---|---|---|
| **生产单号** | ✅ | 按车间的编号规则自己填，系统不自动生成 |
| **产品 ID** | ✅ | 填**商品档案里的数字编号**（不是商品名！） |
| 数量 | ✅ | 整数，最小 1 |
| 优先级 | — | 低 / 正常 / 高，默认正常 |
| 状态 | — | 计划中 / 生产中 / 已完成，默认计划中 |
| 备注 | — | 选填 |

3. 点抽屉底部「**保存生产单**」→ 抽屉自动关，列表里出现新记录。

### 三条防呆提醒

- **产品 ID 填错是最常见的错**。先去「商品档案」把编号抄下来，或者记一下（它就在商品名旁边）。填成商品名会报错。
- **单号别和已有单号重复**。后端会拦，但报错信息在**页面顶部**（红色横幅），不在抽屉里。
- **数量只能是整数**。要按米/公斤算的，请改用"出入库"或调整商品单位。

## 二、BOM 清单

菜单：**生产管理 → BOM 清单**

### 页面现在长什么样

- 上方一句灰字提示，说明"新增已收进右上角"；
- 中间是 **BOM 树**（可展开折叠的层级结构，左边还能搜）；
- 右边/下面是对应节点信息。

### 怎么新增一个 BOM 节点

1. 点「**+ 新增节点**」；
2. 抽屉里有 11 个字段，两两一行：

| 字段 | 必填 | 说明 |
|---|---|---|
| **产品 ID** | ✅ | 这张 BOM 属于哪个成品 |
| **组件 ID** | ✅ | 用哪个零件/原料 |
| 父节点 ID | — | 留空 = 挂在这一层的顶级 |
| 节点类型 | — | 装配 / 组件 / 原材料 |
| 节点名称 | — | 比如"主框架" |
| 编码 | — | 车间内部编码，可留空 |
| **数量** | — | **可以填小数**（0.5 米、1.25 公斤都行） |
| 单位成本 | — | **可以填小数**，别四舍五入 |
| 层级 | — | 0 = 顶层，1 = 第二层，以此类推 |
| 备注 | — | 选填 |

3. 点「**新增 BOM 节点**」保存。

### 三条防呆提醒

- **数量、单位成本支持小数**。BOM 里 0.125 公斤很常见，输入框不会砍你的小数。
- **父节点 ID 要填对**。填错会让树"跑到别的地方去"或者干脆显示不出来。**不确定就先留空**，建完再在树上拖/改。
- **同一个组件在同一父节点下重复添加**通常会合成一行（数量累加），加之前先在树上搜一下。

## 三、常见问题

**Q：抽屉填到一半按了 Esc，白填了？**
A：是的，当前版本 Esc 直接丢弃，没有二次确认。**填很多行时别按 Esc**。

**Q：保存后列表没变化？**
A：列表只显示最近 8 条。去「生产单列表」往下翻，或者看页面顶部的成功提示。若失败，顶部会有红色横幅。

**Q：能批量导入 BOM 吗？**
A：暂时只能用抽屉一条条加。BOM 结构（父子关系）在 Excel 里表达容易出错，所以没做导入。

**Q：生产单和出库单是什么关系？**
A：生产单是"车间要做什么"，出库单是"仓库发了什么料"。成品入库要在**入库单**里做，生产单本身不动库存。
