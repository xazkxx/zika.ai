# 使用说明 —— 对账单三个入口，现在是同一本账

> 给不懂代码的同事看。看完你就知道：三个"对账单"菜单有什么区别、
> 为什么以前会"功能冲突"、现在怎么用、以及核对差额时看哪里。

---

## 一、以前为什么"乱"

系统里曾经有三个都叫"对账单"的东西：

| 菜单位置 | 名字 | 以前的行为 |
|---|---|---|
| 销售管理 | 增强对账单 | 一张**真的对账单**：能存草稿、能勾选核对、能打印盖章 |
| 采购管理 | 采购对账单 | 跳到"往来对账"页，只是**实时算给你看**，存不下来 |
| 销售管理 | 销售对账单 | 同上，也是实时看，存不下来 |

同一个词，两种行为：你在"采购对账单"里看到的数，到"增强对账单"里对不上，
因为它们根本不是同一份数据。这就是"功能冲突"。

## 二、现在是什么样

**三个入口还在原位**（不用改习惯），但点进去的都是**同一个页面**，只是落的方向不同：

| 你点的菜单 | 进来看到 | 相当于 |
|---|---|---|
| 采购对账单 | 范围自动锁在**应付** | 只管供应商的账 |
| 销售对账单 | 范围自动锁在**应收** | 只管客户的账 |
| 增强对账单 | 范围在**全部** | 先看全部台账，想开新单再切方向 |

页面顶部有三个切换按钮：**全部 / 应收 / 应付**。

- **全部**：显示**对账单台账**（所有已存对账单的清单：单号、方向、往来单位、账期、期末余额、状态）。
  点任意一行直接打开这张单核对。这一页**不能生成**新单——生成必须先选方向。
- **应收 / 应付**：和以前的"增强对账单"一模一样——选客户/供应商、选账期、
  点「生成草稿」、勾选明细、保存、打印 PDF / 导出 Excel / 导出 Word。

## 三、新增的"往来账底稿"是干什么的

打开任意一张对账单后，明细下方多了一块
**「往来账底稿（期初 → 逐笔 → 期末）」**，里面有：

- 六张卡：**往来账期初 / 本期增加 / 本期减少 / 往来账期末 / 对账单期末 / 两口径差额**
- 下面摊开这一期的逐笔流水（日期、单号、摘要、增加、减少、余额）

**为什么要有它**：对账单按"开票"记账，往来账按"收付款流水"记账，
两个期末余额**不一定相等**——这不是谁算错了，是口径不同。
差额卡就是帮你一眼看出"差多少"，流水表帮你找到"差在哪几笔"。

⚠️ **系统不会自动调平差额**。差额是业务事实（比如货已收款但发票还没开），
要不要调整、怎么调整，必须人工判断。

## 四、操作步骤（开一张新的应付对账单）

1. 点左侧菜单「采购管理 → 采购对账单」（进来就是应付方向）。
2. 选**供应商**、选**对账期间**，点「生成草稿」。
3. 系统把这期的合同 / 发票 / 收付款汇总成一行行明细，**逐行核对、勾选**。
4. 数字有出入就直接在表里改"已开票 / 已收"，点「保存」——头部金额由系统重算。
5. 核对无误后，在下方"往来账底稿"里看一眼差额，确认对得上。
6. 点「打印 PDF」或「导出 Word」发给对方盖章。

## 五、防呆提示

- **全部模式下没有「生成草稿」**：不是坏了，是故意的——生成必须先定方向。
- **已确认 / 已发送的对账单不能改明细**：只能"作废重开"，否则两份打印稿会对不上。
- **载入下拉里只列当前方向的单**：在"应付"下看不到应收的单，切到"全部"能看到所有。
- **差额不为 0 不一定是错**：先看底稿流水，找出差异来自哪几笔再说。
- 对账单一旦确认就是**法律凭证**，事后补发票不会让它自己变数；
  要让数字变化只能点「重算」这个按钮（且仅草稿可改）。

## 六、常见问题

**Q：我点「采购对账单」，怎么跳到了和对账单编辑器一样的页面？**
A：这就是本次改造的目的——它们本来就是同一本账，只是帮你把方向先选好了。

**Q：以前在"往来对账"页看的实时账还在吗？**
A：在。「财务管理」里的往来对账页没有任何变化，它现在成了对账单详情里
"往来账底稿"的数据来源——两边永远同源。

**Q：差额一直对不上怎么办？**
A：① 看底稿流水里有没有漏登记的收付款；② 看对账单明细里"已开票"是否填了
未入账的发票；③ 还对不上就找财务负责人，不要手动改平。
