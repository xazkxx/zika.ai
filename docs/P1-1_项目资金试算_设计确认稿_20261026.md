## 0. 一句话定位

一个**计算器**：把「一批货的销售 + 采购」喂进模型，吐出「毛利 → 各税 → 净利 → 垫资占用费」。
左边填数（手录 / 从单据**复制一份快照**），右边出三个图。关掉页面什么都不留（草稿只存浏览器 localStorage）。

**为什么值得做**：工程类电缆贸易垫资很重。以附表这两批货为例，净利率 30.94%，
但要垫 186.30 万；付款 30 天、回款 90 天，占用 60 天 × 0.02%/日 = **22,356 元**，
净利率从 30.94% 掉到 29.98% —— 相当于吃掉近 1 个点的净利。这个数不进账、但决定"这单该不该接"。

## 2. 后端唯一口径（逐格对照 Excel，已复算验证）

### 2.1 基础数据（每批 / 合计）

| 行 | 字段 | 公式 | Excel 出处 |
|---|---|---|---|
| L1 | 销售价税合计 | `Σ(数量 × 含税单价)` | 销售表 F7 |
| L2 | 销售不含税 | `销售价税合计 ÷ (1 + 税率)` | D4 `=D3/1.13` |
| L3 | 销售税额（销项） | `销售不含税 × 税率` | D5 `=D4*0.13` |
| L4 | 成本价税合计 | `Σ(数量 × 采购单价)` | 成本表 F7 |
| L5 | 成本不含税 | `成本价税合计 ÷ (1 + 税率)` | D7 `=D6/1.13` |
| L6 | 可抵扣进项 | `成本不含税 × 税率`，**仅当「已取得专票」**，否则 0 | J `=IF(H="是",I*G,0)` |
| L7 | 销售毛利（不含税） | `L2 − L5` | D12 |
| L8 | 销售毛利率 | `L7 ÷ L2` | D13 |

⚠️ **易错点 1**：未取得专票时，成本**不含税金额照旧 ÷1.13**，只是进项按 0 计（Excel 就是这么干的）。
这会让增值税变高 —— 这正是"没有专票要多交税"的真实业务含义，不能"顺手"把不含税也改成含税全额。

### 2.2 应交税金七项（**先 ROUND 到分，再求和**）

| 税种 | 公式 | 是否减半 |
|---|---|---|
| 增值税 | `ROUND(销项 − 进项, 2)` | 否 |
| 城建税 | `ROUND(增值税 × 7% ÷ 2, 2)` | 是（六税两费） |
| 教育费附加 | `ROUND(增值税 × 3% ÷ 2, 2)` | 是 |
| 地方教育附加 | `ROUND(增值税 × 2% ÷ 2, 2)` | 是 |
| 水利基金 | `ROUND(销售不含税 × 0.045%, 2)` | 否 |
| 印花税 | `ROUND((销售含税 + 成本含税) × 0.03% ÷ 2, 2)` | 是 |
| 企业所得税 | `ROUND(税前利润 × 5%, 2)` | 否（小微） |
| **税金合计** | 以上七项相加（都已到分，直接加） | — |

⚠️ **易错点 2**：印花税基数是**含税**金额之和，水利基金基数是**不含税销售额**，两者不能互换。
⚠️ **易错点 3**：附加税三兄弟齐刷刷"× 税率 ÷ 2"，减半是自己写死的一半，不是"六税两费"再打折。

### 2.3 利润链

```
税前利润 = 毛利 − (城建 + 教育 + 地方教育 + 水利 + 印花)      ← 不含所得税，防循环引用
税后净利润 = 税前利润 − 企业所得税
净利率   = 税后净利润 ÷ 销售不含税
```

⚠️ **易错点 4**：所得税**不进**税前利润的扣减项（Excel A41 明确写了防循环）。若按老口径「毛利 × 5%」
（即附加税不从税前扣），第 2 批会算成 26,657.99，比正解多 267.37 —— 这个坑已经踩过一次，测试里要锁死。

### 2.4 合计列的口径（最容易被"想当然"算错的地方）

Excel D 列**不是** B 列 + C 列逐行相加：

- `D3（销售含税） = B3 + C3`、`D6（成本含税） = B6 + C6` ← 只有这两个原始量是相加
- `D4/D5/D7/D8/...` 全部用 **D 列自己的合计口径重新除/乘**，不是 `B4+C4`

原因：`785,582.08/1.13 + 1,831,985.94/1.13 = 2,617,568.02/1.13`，除得尽时两者相等；
但税费项经过 `ROUND`，逐批相加与合计重算会出现分位差，Excel 选了"合计列独立重算"。后端照此实现。

### 2.5 复算验证（本机实跑，Decimal 实现）

| 口径 | 销售含税 | 成本含税 | 毛利 | 增值税 | 所得税 | 税金合计 | 税后净利 | 净利率 |
|---|---|---|---|---|---|---|---|---|
| 两批合计 | 2,617,568.02 | 1,756,297.77 | 762,186.06 | 99,084.19 | 37,727.13 | 144,454.84 | 716,815.41 | 30.94% |
| 第 1 批 | 785,582.08 | 526,782.37 | 229,026.29 | 29,773.42 | 11,336.51 | 43,406.02 | 215,393.69 | 30.98% |
| 第 2 批 | 1,831,985.94 | 1,229,515.40 | 533,159.77 | 69,310.77 | **26,390.62** | **101,048.82** | **501,421.72** | 30.93% |

    city_rate: Decimal = Decimal("0.07")       # 城建税

    ledu_rate: Decimal = Decimal("0.02")       # 地方教育附加
    water_rate: Decimal = Decimal("0.00045")   # 水利基金
    stamp_rate: Decimal = Decimal("0.0003")    # 印花税
    income_rate: Decimal = Decimal("0.05")     # 企业所得税（小微）
    # —— 资金占用（Excel 无，本次新增）——
    capital_daily_rate: Decimal = Decimal("0.0002")  # 日资金成本 0.02%
    pay_days: int = 30            # 付款周期（天，付款给上游）
    collect_days: int = 60        # 回款周期（天，收下游货款）
    prepay: Decimal = Decimal("0")     # 已收预收款（抵减垫资）
    prepay_supplier: Decimal = Decimal("0")  # 已付定金（抵减垫资）

class CalcRequest(BaseModel):
    lines: list[CalcLine] = []

## 4. 资金占用模型（Excel 里没有，本次新增的核心价值）

Excel 只算税，不算钱的时间价值。用户明确要求补上，模型定死三条：

```
1. 垫资额  = 成本价税合计 + 流转税现金支出 − 下游预收 − 上游定金
              流转税现金支出 = 增值税 + 城建 + 教育 + 地方教育 + 水利 + 印花（= 106,727.71）
              ⚠️ 所得税默认**不计入垫资**（按季预缴、不占货款），设置里留
                `include_income_tax_in_advance` 开关，勾上后 垫资额 加回所得税。
2. 占用天数 = max(回款周期 − 付款周期, 0)        # 先付后收才叫垫资；先收后付是负占用，记 0
3. 占用费  = 垫资额 × 占用天数 × 日利率（默认 0.02%/日 = 年化 7.30%）
```

呈现三档，让老板一眼比：

| 指标 | 含义 | 例（两批合计，回款 60 / 付款 30） |
|---|---|---|
| 垫资额 | 这笔生意要压多少钱 | 1,863,025.48（186.30 万） |
| 占用天数 | 压多久 | 30 天 |
| 占用费 | 压钱的成本 | 11,178.15 元 |
| **净利（含资金成本）** | 真正的落袋 | **705,637.26 元** |
| 净利率（含资金成本） | 比毛利率更能说明好坏 | **30.46%**（原 30.94%） |

敏感性（固定付款 30 天，只动回款）：

| 回款周期 | 占用天数 | 占用费 | 净利 | 净利率 |
|---|---|---|---|---|
| 30 天 | 0 | 0.00 | 716,815.41 | 30.94% |
| 60 天 | 30 | 11,178.15 | 705,637.26 | 30.46% |
| 90 天 | 60 | 22,356.31 | 694,459.10 | 29.98% |
| 120 天 | 90 | 33,534.46 | 683,280.95 | 29.50% |

**给老板的一句话结论（前端按数据自动生成）**：
> "毛利率 32.90%、净利率 30.94%；但要垫 186.30 万、压 30 天，资金成本 11,178 元，折完 30.46%。
> 回款拖到 120 天，资金成本 33,534 元、净利率掉到 29.50% —— 这单能接，账期别破 60 天。"
