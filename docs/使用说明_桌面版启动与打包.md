# 使用说明：桌面版怎么启动 / 怎么打包

> 面向：日常使用者 + 负责打包的同事
> 更新：2026-10-19（修复「双击 ERP管理系统.exe 没反应」）

---

## 一、双击 exe 到底发生了什么

以前双击 exe 会弹出一个独立的程序窗口，关掉窗口整个系统就退出。
为了让手机也能用（扫码进同一个地址），我们把那个窗口去掉了，改成一件事：
**在后台常驻一个网站服务，用浏览器来用系统。**

去掉窗口时漏了一步：没有自动把浏览器打开。于是双击 exe 的真实情况是：

- 程序**确实启动了**，端口 8010 也在正常监听；
- 但屏幕上**什么都不出现**，任务栏也没有图标（它是后台进程）；
- 看起来就像"点了没反应 / 崩溃了"。

**这是体验缺陷，不是程序坏了。** 现在的版本已经补上自动打开浏览器。

## 二、日常启动（两种方式任选）

### 方式 A：双击 `ERP管理系统.exe`（打包版，给其他人用）

1. 双击 `ERP管理系统.exe`；
2. 等 1~5 秒，**浏览器会自动打开** `http://127.0.0.1:8010`；
3. 用 admin / Admin123 登录。

如果浏览器没自己弹出来：手动打开浏览器，地址栏输入 `http://127.0.0.1:8010` 回车即可。

### 方式 B：双击 `启动ERP.bat`（源码模式，给本机开发用）

同样会自动打开浏览器，效果一致。

### 怎么关掉它

它是后台进程，没有窗口可关。用任务管理器结束 `ERP管理系统.exe`（或 `pythonw.exe`）即可，
也可以在命令行执行：

```bat
taskkill /F /IM "ERP管理系统.exe"
```

## 三、三个最容易踩的坑

### 1. 提示"端口被占用" / 打开页面是一片空白

说明系统**已经在运行了**。新版 exe 会自动识别这种情况，直接把已有页面打开，
不会再报错。如果页面还是白的，按 **Ctrl + Shift + R** 强制刷新一次。

### 2. 上传过的合同/发票附件"找不到文件"

附件不放在程序里面，而是放在 **exe 旁边的 `data` 文件夹**。
换电脑、换目录部署时，要把整个 `data` 文件夹一起拷过去（放在 exe 同一层）：

```powershell
# 在 ERP 项目根目录执行，把存量附件复制到 exe 旁边
robocopy "data" "dist\ERP管理系统\data" /E
```

新上传的文件会自动建目录，不用手动建。

### 3. 双击后真的什么都没发生，连浏览器也没开

看 exe 同目录下的 **`erp_error.log`**：

- 文件存在 → 里面写着失败原因（缺文件、连不上数据库等），把它发给我；
- 文件不存在 → 程序没崩，只是没开浏览器，手动访问 `http://127.0.0.1:8010` 试试。

新版在启动失败时还会**弹一个提示框**，不会再有"静默失败"。

## 四、给打包同事的说明

### 正式打包

```bat
cd /d E:\AI\ERP软件
.venv\Scripts\pyinstaller.exe --noconfirm erp.spec
```

⚠️ 打包前**必须先关掉正在运行的 `ERP管理系统.exe`**，否则 `dist` 目录被占用，打包会失败。

产物：`dist\ERP管理系统\`（整个文件夹一起发走，不能只拷 exe）。

### 排查用的"调试包"

```bat
cd /d E:\AI\ERP软件
set ERP_CONSOLE=1
.venv\Scripts\pyinstaller.exe --noconfirm erp.spec
```

调试包带一个黑色命令行窗口，报错直接印在屏幕上（正式包没有黑框，靠 `erp_error.log` + 弹窗留痕）。

### 哪些东西打进了包、哪些没有

| 资源 | 是否打包 | 说明 |
|---|---|---|
| `frontend/dist` | ✅ 打 | 前端页面，缺了就是白屏 |
| `.env` | ✅ 打 | 数据库连接串 |
| `data/` | ❌ 不打 | 用户上传的附件（22MB），属于运行期数据，放在 exe 旁边 |
| `templates/` | — | 本项目没有这个目录，打印模板存在数据库里，无需打包 |
| pywebview / .NET | ❌ 不需要 | 桌面窗口代码已彻底移除，改成纯浏览器访问 |

### 可选环境变量

| 变量 | 作用 | 例 |
|---|---|---|
| `ERP_PORT` | 换端口（默认 8010） | `set ERP_PORT=8000` |
| `ERP_NO_BROWSER` | 设 `1` = 只跑服务、不自动开浏览器（开机自启/服务器部署用） | `set ERP_NO_BROWSER=1` |
| `ERP_CONSOLE` | 设 `1` = 打调试包（带命令行窗口） | `set ERP_CONSOLE=1` |

## 五、局域网 / 手机访问

服务监听的是 `0.0.0.0:8010`，同一 WiFi 下的手机可以直接访问：

```
http://<这台电脑的局域网IP>:8010
```

查本机 IP：命令行执行 `ipconfig`，看"IPv4 地址"。
首次访问如果打不开，检查 Windows 防火墙是否放行了 8010（可双击 `配置局域网访问.bat`）。
