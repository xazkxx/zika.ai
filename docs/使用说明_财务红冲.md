# 财务红冲 · 使用说明

> 给业务同事看的操作手册。看不懂代码没关系，照着做就行。

---

## 一、这个功能是干什么的？

收错钱、收多了、重复登记了……以前这种流水**改不了也删不掉**，只能一直挂在账上。

现在有了「红冲」：在财务流水列表里，对**收错的那笔**点一下「红冲」，系统会自动生成一笔**方向相反的冲抵流水**（收了 1000 就冲出 -1000），两笔相加正好归零。原来的记录**不会消失**——谁收的、什么时候收的、为什么冲，全都留痕。

一句话：**钱收错了不删记录，用一笔反向记录把它抵掉。** 这和会计上的"红字冲销"是一个道理。

---

## 二、功能入口在哪里？

**财务管理 → 财务流水**。

只有两种流水可以红冲：

- ✅ **收款**（客户付给我们的钱）
- ✅ **付款**（我们付给供应商的钱）

其他类型（手工登记的收入/支出等）**没有红冲按钮**——它们不挂单据，弄错了走对应的业务单据改。

---

## 三、操作步骤（跟着做）

### 第 1 步：找到要冲的那笔流水

在财务流水列表里，找到收错（或付错）的那一行。可以用搜索框按单号、对方名称过滤。

**能红冲的行**，行尾会有一个红色的 **「红冲」** 按钮。注意三种情况按钮不会出现：

- 这笔钱**已经冲过了**（状态列会显示红色「已冲销」标签）
- 这一笔**本身就是红冲产生的**（状态列显示「红冲」标签，负数金额显示红色）
- 不是收款 / 付款类型

### 第 2 步：点「红冲」，看清楚弹窗内容

点「红冲」后弹出一个确认框，上面写着：

- 要冲的**金额**
- **关联的单据**（哪张销售/采购单）
- **业务日期**

请在**「冲销原因」**里写清楚为什么冲，比如：

> "客户重复转账，冲回多收的 300 元"
> "录入时金额敲错，1000 应为 100"

原因会留在记录里，日后对账时一目了然。

### 第 3 步：点「确认红冲」

确认后系统立刻生成一笔**负数流水**，并且**自动把原来销售/采购单上的已收（已付）金额减回去**。

刷新列表你会看到：

- 新出现一笔**红字（负数）**流水，状态标签是「红冲」；
- 原来那笔的状态变成了 **「已冲销」**（红色标签）；
- 打开流水详情（点行），能看到它冲的是哪一笔 / 被哪一笔冲的。

## 四、核心业务规则（为什么这么设计？）

### 1. 为什么红冲后不能删单？

一笔钱只要**真的发生过**（银行流水里进来了），账上就必须留痕。红冲的本质是"两笔记录、净额为零"，历史完整可查。

如果允许把相关单据删掉，这两笔流水就变成**没有来路的孤儿账**——审计对不上、税务说不清。所以系统规定：**发生过收付款的单据不能删，只能红冲**。删除时系统会直接拦下并提示。

### 2. 为什么一笔只能冲一次？

「已冲销」的行不再显示红冲按钮。因为：

- 冲两次就等于冲了双倍金额，账就乱了；
- 每一笔红字都指向它冲的那笔原账，一对一关系，账目才能互相印证。

如果冲错了怎么办？红冲本身不能"反冲"——请**再走正常收款/付款**把正确的钱登进去，需要说明的在备注里写清楚。

### 3. 为什么红冲会自动减单据上的已收金额？

你在销售单上看到"已收 1000"，凭据就是流水。冲掉其中 500，单据上的"已收"如果还是 1000，业务员就会以为客户还差 500 其实已经结清了。

所以红冲时系统**同步把单据的已收（已付）金额减回去**，减多少？不是冲多少减多少，而是**这笔流水实际落到单据上的金额**。比如：单据欠 1000，你却收了 1500（多收 500），后来把那笔 1500 冲掉——单据只会减掉它实际收到的 1000，不会减成负数。

### 4. 为什么总账也一起变？

红冲生成的红字流水会**同步生成一张方向相反的总账凭证**（借贷对调）。这样总账和流水永远对得上，月底不用人工调整。

## 五、防呆提示（遇到这些情况怎么办？）

| 提示 / 现象 | 原因与解决办法 |
| --- | --- |
| 行尾没有「红冲」按钮 | 只有收款/付款可以红冲；已被冲销的、红字行都不行（看「状态」列）。 |
| 提示"该流水已被冲销" | 一个人抢先冲了（或你点了两次）。刷新列表看状态。 |
| 提示"请重启「启动ERP.bat」" | 后端服务刚升级还没重启，联系管理员重启即可，数据没有丢。 |
| 弹窗里没有显示关联单据 | 这笔流水可能是手工登记的。手工收付款也可以冲，单据栏会显示"无"。 |
| 冲完后单据"已收"没变？ | 冲的是手工登记、没挂单据的流水，或者这笔钱实际没落到那张单上——点开流水详情看「关联单据」。 |
| 状态列显示红色「已冲销」 | 这笔已被冲掉，是历史记录，不能再操作。 |
| 状态列显示「红冲」、金额红色负数 | 这是冲抵产生的记录本身，不是重复记账。 |

## 六、一图看懂

```
正常流水（收 1,000）          状态：正常
      │ 点「红冲」+ 填原因
      ▼
原流水（收 1,000）            状态：已冲销（红色标签）
新流水（-1,000，红字）        状态：红冲
      │
      ▼
两笔相加 = 0，单据已收金额同步减回，总账同步生成反向凭证
```
