# 使用说明：发票关联单据 + 销售出库物流签收

> 面向业务人员，不出现任何技术术语。看完你应该能回答两个问题：
> ① 这张发票是哪张单开的？② 这批货客户签收了吗？谁签的？什么时候？

---

## 一、这次改了什么（一句话版）

以前发票是"孤岛"：只知道开给了谁、多少钱，不知道对应哪张单；出库也是"发完就没下文"，签收全靠微信里问。
现在两件事都补上了：**发票能挑单**，**出库能登记物流和签收**。

---

## 二、入口一：给发票挑一张单

### 在哪
左侧菜单 → **财务管理 → 发票管理** → 在发票那一行点 **「编辑」**。

### 怎么操作
1. 弹窗里找到 **「关联单据」**（在「开票方式」下面，整行那条）。
2. 点一下那个框，直接**打字搜**：可以搜单据号，也可以搜客户名。
   - 销项发票（我们开出去的票）→ 候选里是**销售单**
   - 进项发票（别人开给我们的票）→ 候选里是**采购单**
   - 候选后面灰色小字是「日期 · 金额」，用来确认别挑错。
3. 选中 → 下方小字变成绿色：**「已关联。对账单就是靠这一列把「开票金额」算出来的。」**
4. 点 **保存**。

### 怎么知道哪些票还没挂
发票列表里，号码下面会多一行小字：

| 显示 | 含义 |
|---|---|
| `单 XS20261019001` | 已经挂在这张销售单上 |
| `未关联`（土黄色） | **这张票还没挂单**，对账单里算不出它的已开票金额 |
| 什么都不显示 | 进销项还是「待判定」，先判定再挂 |

### 为什么要这么做（业务规则）
- 对账单里有三个数：**合同金额 / 已开票金额 / 未开票金额**。
  其中「已开票金额」不是按客户名字加总出来的，而是**按这张票挂的那张单**归集的。
  票不挂单 = 这个数永远是 0，客户明明开了票，对账单上却显示"一分没开"。
- 之前账上就是这个状态：4 张销项发票一张都没挂，三张对账单的「已开票金额」全是 0.00。

### 防呆提示
- **进销项没选，挂不了单。** 先在上面把「进销项」选成进项或销项，选择器才会解锁。
- **已经挂了单，就不能直接改进销项。** 系统会拦住并提示"请先清空关联单据"。
  原因很实在：一张销项票挂着销售单第 4343 号，你把它改成进项之后，同一个 4343 会指向采购单里的另一张单 —— 数字看着正常，其实是错的。**这类错最难发现，所以宁可不让改。**
- **销项票选了采购单，会被拦下来。** 同上，方向必须对。
- **解除关联**：把框里的内容清掉（点右边的 ×）再保存即可。

## 三、入口二：登记物流与签收

### 在哪
左侧菜单 → **销售管理 → 开单管理**（就是销售出库那页）→ 下面「销售出库单列表」里**点任意一行**，弹出单据详情。

### 怎么操作
详情里有一块 **「物流 / 签收」**，右上角有状态角标（**已签收** / **未签收**）：

| 字段 | 填什么 | 例子 |
|---|---|---|
| 物流公司 | 谁运的 | 顺丰 / 德邦 / 自送 |
| 物流单号 | 快递单号或运单号 | SF1234567890 |
| 签收人 | **客户方**签字的那个人 | 张三 |
| 签收时间 | 客户实际签收的时间 | 2026-10-19 15:30 |

填完点 **「登记签收」**（已经签过的显示「更新物流/签收」）。

### 开单时也能填
同一页上方的开单表单里，也加了这四个输入框。发货当场就知道物流信息的，直接一起填，不用开完再回头补。

### 为什么要这么做（业务规则）
对账单要能对着客户讲清一条链：**这张单 → 哪天发的 → 谁签的 → 开了多少票 → 收了多少钱**。
签收时间就是"货确实到了"的唯一凭据；没有它，客户说"没收到货"，账面上讲不清。

### 防呆提示
- **签收时间不能填未来。** 填了会被拦（未来的签收会让"已签收多少天"变成负数）。
  补录昨天的签收单没问题，**允许填过去的任何时间**。
- **只订货、没发货的单，不能登记签收。** 那种单叫「销售订单」，货还没出库，签收是无意义的。
  系统会提示你去「销售出库单」上登记。
- **签收时间留空 = 这张单回到「未签收」。** 填错了可以撤回，不用找管理员。
- **物流单号不会自动校验真假**，它就是给你自己和对账时查的。

## 四、两个常见问题

**Q：发票挂错单了，已经保存了，怎么办？**
重新点「编辑」，把「关联单据」清空（点 × ），保存；再选正确的单，保存。系统不会留历史痕迹，直接覆盖。

**Q：为什么有的发票搜不到单？**
先看它的「进销项」判成什么了。判成「待判定」时选择器是灰的 —— 系统不知道该去销售单里找还是采购单里找。
判定方法：在「系统设置 → 公司信息」里把本公司名称和税号填好，再回发票页点「一键重判」。

## 五、验收清单（照着点一遍就行）

1. 打开一张销项发票 → 编辑 → 「关联单据」能搜到销售单 → 选中保存 → 列表里出现 `单 XS…`。
2. 打开一张出库单 → 详情里有「物流 / 签收」四个框 → 填完保存 → 角标从「未签收」变「已签收」。
3. 把签收时间改成明天 → 提示"不能晚于现在"。
4. 把一张已挂单的发票改成另一种进销项 → 提示"请先清空关联单据"。
5. 发票列表里没挂单的票，号码下面能看到土黄色的「未关联」。
