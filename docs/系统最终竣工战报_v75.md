## 二、改了什么（按你的任务单逐条对账）

### 任务一 · 第三阶段 UI 大重构

#### ① 库存管理看板化 ✅

**改之前**：一张几千行的平铺表，靠筛选往下翻。
**改之后**：

- **顶部三张可点卡片**：总库存量 / 库存总金额（成本）/ 缺货（小字还带低库存、积压数）
- **分段筛选**：按仓库 / 按分类 / 按状态 —— 原有搜索框融进同一行工具栏，不再单独占一行
- **汇总卡片区**：一张卡 = 一组，卡上直接写：商品数、数量、金额、行数、缺货/低库存/积压小标签
- **自动排序**：缺货 → 低库存 → 积压 → 正常，同档按金额降序。**第一张卡永远是最该处理的**
- **点卡下钻**：点卡片 → 下面明细表只显示这一组 → 「← 返回看板」回来 → 再点同一张卡也能收起
- **手工出入库**从常驻表单收进右侧抽屉
- 卡片左边框按紧急度上色：缺货红、低库存橙、积压靛蓝、正常灰

> 金额口径写清楚了：**数量 × 商品档案采购价**，不含运费税费。点金额卡会弹提示说明。

## 四、这轮踩过的最狠的坑（给你留个底）

### `ctx` 解构遮蔽 React Hook → 整页白屏，`vite build` 完全不报错

`pages/*.jsx` 顶部固定是 `const { useState, useMemo, ... } = ctx;`，
而 `appCtx` 里恰好也导出了 `useState` / `useMemo` 这些键。

同一作用域里，**后声明的 `const` 覆盖 `import`** → 运行时抛
`ReferenceError: Cannot access 'xx' before initialization` → **整页白屏**。
而 `npm run build` 一路绿灯，静态检查也查不出来。

**解法**：四个页面统一改成别名导入

```jsx
import { useMemo as useLocalMemo, useState as useLocalState } from 'react';
```

**以后新增页面第一件事**：先看 ctx 解构里有没有 `useState` / `useMemo`，有就必须用别名。

（其余坑见 `docs/v75_第三阶段看板化重构记录.md`：变量名撞 ctx 键、`ResizableLayout` 只认 2 个子元素、正则改 JSX 打断箭头函数、`table-layout:fixed` 下 `min-width` 无效。）
