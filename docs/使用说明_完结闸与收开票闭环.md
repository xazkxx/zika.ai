# 使用说明：完结闸与收款/开票闭环（2026-10-20）

> 给不懂代码的业务同事看的。一句话版本：**一张销售出库单，要"钱收齐、票开齐"才能标记为已完结；差一样，按钮就是灰的，点了也没用（后端也会拦）。**

---

## 一、这个功能解决什么问题

以前「标记为已完结」按钮谁都能点：钱没收齐也能点，票没开也能点。点了之后单子变"已完结"，账上却还挂着没收的钱、没开的票，月底对账全是糊涂账。

现在系统把这扇门锁上了：

1. **没结清 → 完结按钮置灰**，鼠标放上去提示"尚有未结清款项或未开具发票，无法完结"；
2. 就算绕过按钮（比如两个人同时开着页面），**后端也会拒绝**，返回明确的提示；
3. 在列表里补上了「收款」「开票」两个按钮，让"收齐、开齐"在同一个页面就能做完。

## 二、在哪儿用、怎么用

### 入口：「开单管理（销售出库单）」页面

右侧列表每一行的「操作」列，现在有 6 个按钮（从左到右）：

| 按钮 | 什么时候点 | 点了会发生什么 |
|------|-----------|---------------|
| 打印 | 要打出库单 | 下载 PDF |
| 送货单 | 要给司机/客户送货单 | 下载 PDF |
| **收款**（新） | 客户给了钱 | 弹出收款登记框，登记后本单"应收余额"减少 |
| **开票**（新） | 给客户开了发票 | 弹出开票登记框，登记后本单"未开票金额"减少 |
| **完结**（新） | 钱收齐 **且** 票开齐 | 单子变"已完结"（之前这个按钮是灰的） |
| 删除 | 单子录错了 | 弹出确认框 |

点列表任意一行打开**详情弹窗**，底部也有同样的三个按钮（收款 / 开票 / 标记为已完结），弹窗里还多一行**结算信息**：`应收余额 ¥… · 未开票 ¥…（可完结/未收齐）`。

### 标准操作顺序（重要）

1. 开单 → 单子出现在列表，完结按钮是**灰的**；
2. 客户付钱 → 点「收款」，填金额（比如 ¥1000）→ 应收余额变 0；
3. 开出发票 → 点「开票」，填发票号码和金额（金额已按"还没开票的钱"预填好）→ 未开票变 0；
4. 两项都清零后，完结按钮**自动亮起**（列表和详情弹窗都会自动刷新，不用手动重进页面）→ 点「完结」。

## 三、核心业务规则（为什么会这样设计）

### 1. 什么叫"结清"？

系统对每张出库单算三个数：

- **应收余额** = 单据金额 − 已经收到的钱；
- **未开票金额** = 单据金额 − 已经挂到这张单上的销项发票金额；
- **两个都 ≤ 0**，才算"结清"，完结按钮才亮。

> 多收了钱（预收）、多开了票，余额会是负数，同样算"结清"——这是故意的，不会把你锁死。

### 2. 分次收款、分次开票都可以

每次收一部分、每次开一部分都行，系统按累计金额算。开票弹窗里的金额默认填"还没开票的部分"，你可以改小做分次开票。

### 3. 发票号码输错了会拦你（防呆）

系统里如果**已经存在同一个发票号码**的发票，登记时会直接拦下并提示，不会让你保存。原因：底层保存同号发票会"删旧建新"（那是给 OCR 批量上传设计的），手输抄错一位号码就会把库里那张真发票顶掉。

### 4. 已完结的单子删不掉（这是对的）

完结之后单子上带着真实的收款流水，删除会被拦（提示需要处理资金流水）。金额登错了应该走**红冲**，不是删单——删单会让收过的钱变成"无主账"。

### 5. 「销售订单」页不受影响

只有**真实出库**的开单（销售出库单）受完结闸管。「销售订单」是订货意向，它的"已完结"由转开单流程自动处理，不弹这个闸。

## 四、常见问题

**Q：按钮一直是灰的，钱明明收了？**
刷新一下页面（按 F5）。收款登记是实时生效的，但如果页面开着很久没动，显示的可能是旧数据。

**Q：收款弹窗提示"该订单没有关联客户"？**
这张单开单时没选客户档案。先补客户档案，再登记收款。

**Q：我不小心把发票号登记错了怎么办？**
到「发票管理」页删除那张错票，然后重新登记。注意：删掉后这张单的"未开票金额"会涨回来，完结按钮会重新变灰。

**Q：完结之后还能收款/开票吗？**
可以（比如补录场景），但一般不应该出现——完结的前提就是钱票两清。
