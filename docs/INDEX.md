## 七、维护规则（请照这个来，否则索引两个月就又废了）

1. **命名**：面向用户的手册 → `使用说明_<主题>.md`；开发/修复记录 → `<主题>_YYYYMMDD.md`（必须带日期）。
2. **登记**：任何新文档写完后，在本文对应分节加一行（链接 + 一句话 + 状态），不改索引等于没写。
3. **状态**：现行有效标 ✅，过时但留作证据标 📦。**不要删**——"为什么这么改"比代码本身更难重建。
4. **位置**：`docs/` 根目录只放 `.md`；截图/样张/脚本放对应子目录（`验收截图/`、`样张_Word导出/`、`sql/`）。
5. **反证**：性能/精度/红冲这类改动，文档必须写清"怎么验证的、跑了多少项断言"，别只写"已修好"。
