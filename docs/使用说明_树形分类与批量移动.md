# 使用说明 · 树形分类下拉与商品批量移动

> 面向业务人员，不需要懂技术。看完你会知道：分类怎么选、商品怎么批量挪类别、选错了怎么退回来。

---

## 一、分类下拉变了：从"一长串路径"变成"能收能放的树"

### 以前是什么样

点开「所属分类」下拉，几十个选项一股脑全铺出来，长这样：

```
中铁一局集团 / 华北分公司 / 劳保鞋
中铁一局集团 / 华北分公司 / 安全帽
中铁一局集团 / 西北分公司 / 劳保鞋
中建三局 / 华中分公司 / 劳保鞋
……
```

问题是：**你只想选"劳保鞋"，却要先在一堆重复的长字符串里找**。分支一多，下拉框能拉出半屏。

### 现在是什么样

点开下拉，**只显示第一级**（比如「中铁一局集团」「中建三局」「五金」「劳保」）。点一下带数字的父级，它才展开下一层；一层一层往下点，直到最末一级才是"选中"。

**关键区别：点父级 = 只是展开，不会选中。** 只有点最末一层的节点，才会真的填进输入框。

### 三个最常用的动作

| 你想干什么 | 怎么做 |
| --- | --- |
| **找某个分类** | 直接在搜索框打关键字（如"劳保鞋"），命中路径会自动展开，无关分支自动隐藏 |
| **选中某个分类** | 点到最末一级（后面没有数字标记的那一行） |
| **让商品/客户不属于任何分类** | 点面板最上方的「未分类（不归属任何分支）」 |

### 选完之后

输入框里回显的是**完整路径**，比如「中铁一局集团 / 华北分公司 / 劳保鞋」。这样同名分类（不同分支下可能有重名）不会搞混。

### 一个防呆提醒

⚠️ 如果你之前**手动打过**一个不在这棵树里的分类名（老系统留下的自由文本），再打开这个下拉时，输入框会**照原样显示那个名字**，不会变空白。

这是故意的。如果显示成空白，你可能以为"本来就没分类"，顺手一保存就把历史值清掉了。

## 二、商品批量移动：一次把一堆商品挪到同一个分类

### 什么时候用

录完一批商品，发现它们都归错了类别（比如都进了「未分类」），一个个点开改太费劲。这时用批量移动。

### 操作步骤

1. 打开「基础资料 → 商品档案」。
2. 先点左侧类别树的「全部商品」（不点的话列表是空的，这是设计，不是出错）。
3. 在列表里**勾选**要移动的商品（左侧复选框，可多选）。
4. 勾选之后，列表下方（或上方操作条）会出现「**批量移动**」按钮，点它。
5. 弹出一个小窗，标题写着「批量移动 N 个商品」。
6. 在小窗里用树形下拉选一个**目标分类**（操作同上：逐层点开，点末级）。
7. 点「移动 N 个商品」。

成功后顶部会出现一行提示：`已把 N 个商品移到「xxx」`。列表自动刷新，刚才勾选的商品已经在新的分类下了。

### 想把这些商品的分类**清空**怎么办

在树形下拉里点最上面那一行「**未分类（清空这些商品的类别）**」。

此时小窗里会出现一行黄色提示：
> 已选择「未分类」：这 N 个商品的类别会被清空。

确认无误再点移动。**这是唯一会清空分类的入口**，故意做得显眼。

### 三个防呆设计（为什么按钮点不动）

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 「移动」按钮是灰的，点不动 | 你还没选目标分类 | 先在小窗里选一个分类 |
| 小窗里有红字「还没选目标分类，…」 | 同上，只是说得更明白 | 同上 |
| 点「移动」后出现红字「请先选择一个目标分类」 | 你按了回车想提交，但分类还没选 | 同上 |

**为什么这么设计**：分类是必填的。如果允许"什么都没选"就提交，接口只能理解成"把它清空"——那你勾了 50 个商品、点一下确认，分类就被清空了。所以前端直接不让点，**一个请求都不发**。

## 三、出错了会看到什么

| 你看到的提示 | 什么意思 | 怎么解决 |
| --- | --- | --- |
| 请先勾选要移动的商品 | 没勾任何商品就点了批量移动 | 回列表勾选 |
| 缺少目标分类（要清空分类请传空字符串 ""） | 程序调用参数不完整 | 正常操作不会遇到；遇到请重开小窗再试 |
| 目标分类不能为 null（要清空分类请传空字符串 ""） | 同上 | 同上 |
| 分类名称过长（最多 100 字） | 分类名超过 100 个字符 | 换个短一点的名字 |
| 非法 id：'xxx' | 勾选数据有问题（极少见） | 刷新页面重新勾选 |
| 批量移动失败（500） | 后端出了异常 | 稍后重试；反复失败请联系管理员 |

**提示一定是一行中文**，不会出现 `[object Object]` 或一串看不懂的英文——这是本次专门修的地方。

⚠️ 如果你以前试批量移动时遇到过"**点完整个页面变白、什么都不能点**"，那是旧版本的缺陷（错误信息里带了程序对象，界面渲染不动直接崩了）。本次已修复，请按下面"升级后第一次打开"做一遍。

## 四、升级后第一次打开：请强制刷新一次

浏览器会把旧版页面缓存起来。**如果你不强制刷新，可能看到的还是旧界面**（这就是之前"改了但没生效"的常见原因）。

### 怎么做

- **Windows**：按 `Ctrl` + `Shift` + `R`
- 或者在页面上按 `F5` 长按 / 打开开发者工具后勾选「Disable cache」再刷新

刷完看页面底部或关于页的版本号，变成新版本就对了。

## 五、这次改了什么（一句话版）

1. 客户、供应商、商品三处的「所属分类 / 类别」下拉，全部换成**能逐层展开、能搜索、只显示第一级**的树形下拉。
2. 商品列表新增「**批量移动**」：勾选多个商品，一次移到同一个分类（或清空分类）。
3. 商品弹窗的「生产商」改成**从供应商档案里搜**（输入名称或助记码都能搜），不再手打。
4. 批量移动的报错**不再白屏**，一定给一行中文提示。
5. 后端接口在参数不全时会**明确拒绝**（而不是把分类悄悄清空然后说"成功"）。
