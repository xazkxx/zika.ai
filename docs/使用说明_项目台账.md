# 使用说明：项目台账（抽屉版 + 操作列修复）

> 面向：项目经理、工程部、老板
> 版本：v75（2026-10-20）
> 一句话：**新增改到右边抽屉，表格操作列的三个按钮不再挤成一团。**

菜单：**项目管理 → 项目台账**

---

## 一、这次修了两个问题

### 问题 1：新增表单占满了屏幕

以前一进"项目台账"，左边竖着一个"新增项目"大表单，表格被压到右边只剩两条窄窄的列，看都看不清。

**现在**：页面进来直接是满宽的表格，新增收到右上角「**+ 新增**」里。

### 问题 2：操作列按钮挤成一团

以前操作列（"详情 / 编辑 / 删除"）宽度不够，三个按钮会**折成两行甚至三行**，行高忽高忽低，鼠标老是点错。

**现在**：

- 操作列固定 **168px** 宽，三个按钮**永远一行排开**；
- 其它列也给了固定宽度（编码 120、状态 90、进度 92、负责人 72、截止 110、预算 104），名称列自动吃掉剩余宽度；
- 窗口再窄也不会把按钮挤变形，表格整体会左右滚动（鼠标滚轮 + Shift 或直接拖底部滚动条）。

---

## 二、怎么新增一个项目

点右上角「**+ 新增**」→ 右侧抽屉，填这些：

| 字段 | 必填 | 说明 |
|---|---|---|
| **项目编码** | ✅ | 内部唯一编号，建议 `PRJ-2026-001` 这种规则 |
| **项目名称** | ✅ | 客户能看懂的名字 |
| 负责人 | — | 填人名 |
| 状态 | — | 从下拉里选（进行中 / 已完成 / 已暂停 等） |
| 进度 % | — | 0~100 的整数 |
| 预算 | — | 金额，**支持小数**（可以填 128000.55） |
| 截止日期 | — | 点日期框选 |
| 备注 | — | 选填 |

填完点抽屉底部「**保存项目**」→ 抽屉关上，列表刷新。

**防呆提醒：**

- **保存中按钮会变「保存中…」并且变灰**，这是防止点两下建出两个项目；
- 编码重复后端会拦（红色横幅在页面顶部）；
- 进度填 100 不会自动把状态改成"已完成"——**这两件事是分开的**，改完进度记得手动改状态。

---

## 三、编辑和删除

- **编辑**：点行末「编辑」→ 弹出居中的小窗口（编辑还是用弹窗，因为字段少、改完就关）；
- **删除**：点「删除」→ 会先问你一次；
- **详情**：点「详情」看完整信息。

三个按钮都在**同一行**，从左到右，不会换行。

## 四、常见问题

**Q：表格右边被截断了怎么办？**
A：表格容器可以横向滚动。用鼠标按住表格底部的滚动条拖，或者把鼠标放在表格上按 `Shift + 滚轮`。

**Q：为什么"进度"列那么窄，100 显示不全？**
A：进度列宽 92px，够放 `100%`。如果显示被截，通常是浏览器缩放（Ctrl + 0 恢复 100%）。

**Q：项目能关联到具体订单/合同吗？**
A：当前版本项目台账是独立台账，不直接挂销售单。要在合同上标项目，用合同里的备注字段。

**Q：抽屉和"编辑"弹窗为什么一个是抽屉一个是弹窗？**
A：新建字段多、抽屉宽，填着舒服；编辑字段少、改完就走，居中弹窗更聚焦。这是刻意区分的。
