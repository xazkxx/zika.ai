## 二、功能模块清单（按业务域）

### 1. 基础档案
- **客户 / 供应商**：树形分类 + 列表联动、左树未选中显示空态（设计行为）、批量移动分类
- **商品**：SKU 档案、多单位换算（sales-units「只乘不除」口径）、商品类别树**拖拽排序**（`POST /product-categories/{id}/move`）
- **仓库 / 员工 / 组织机构 / 项目台账**（项目编号可搜索选择）
- 通用组件：`ErpTreeSelect`（树选择）、`ErpSearchSelect`（搜索下拉，几百条档案不卡）、`ResizableLayout`（可拖拽分栏）

### 2. 采购链
采购订单（订货意向，不动库存）→ 审核 → **转入库单**（真实写库存+应付）→ 采购退货 → 付款登记。
防呆：转单按钮请求飞行期禁用（防双击转出两张单）；已转单显示「已转入库」灰标而非按钮凭空消失。

### 3. 销售链
报价单 → 销售订单 → 审核 → **转开单**（销售出库：扣库存 + 记应收）→ 物流签收 → 收款 → 开票 → **完结闸**（未结清或未开齐发票不许完结）。
- 反审核：只退草稿、账一分不动；有流水一律 409 拒绝
- 发票登记支持关联出库单；**历史销售单导入**的单直接落 submitted（见 §5）

### 4. 库存
期初建账（导入幂等覆盖）、调拨、盘点、报损溢、库存看板、库存预警（stock-alert）。
每笔出入库一行流水，`related_type/related_order_id` 全程可追溯。

### 5. 生产
生产单 / BOM / MRP / 委外加工 / 领料退料 / 成品入库，与库存流水同一口径。

### 6. 资金与财务
- 资金流水（收/付/其他收支）、银行账户
- **财务红冲**：唯一撤账入口，四条铁律（只冲收付款、一笔只冲一次、加负数流水不删不改、`applied_amount` 回退），红字必须 `post_reversal_entry()`
- **会计凭证**：单据自动生成借贷双分录，逐单可查
- 反审核 = 只退草稿；**作废/红冲才是撤账**，两者语义严格分离

### 7. 发票与对账
- 发票关联单据登记、未开票金额进完结闸口径
- **对账单三入口统一**（客户/供应商/单据侧同一份生成逻辑，四个断点待收尾）

### 8. 合同
合同管理 + **OCR 识别**（扫描件上传自动提取要素）。

### 9. 报表与看板
报表中心（时间选择器）、库存看板、经营总览。**全站手写 SVG 图表**，零第三方图表库（离线可用）。

### 10. 系统管理
用户 / 角色权限（`PERMISSION_CATALOG` + 菜单可见性四层联动）/ 菜单管理 / 数据字典 / 参数 / 操作日志 / 外部端 API 指南（`外部端接入_API指南.md`）。

### 11. 数据导入导出（本轮重点）
- **7 类模板**：商品/客户/供应商/仓库/员工/期初库存/历史销售单；导出与模板**共用同一份列定义**，导出文件改完可直接导回
- 档案导入：按编码 upsert（存在则更新/不存在则新建），`mode=skip` 可选；单行失败不拖垮整批；预检（dry_run）不落库
- **界面入口**：各档案页右上角「导入」；历史销售单在「销售出库」页「导入历史单」按钮
- **历史销售单导入引擎**（`app/services/sales_history_import.py`，17 条专项测试）：
  - 多行合成一张单（同单据编号）、跨工程自动拆单（`-01/-02` 后缀）
  - **整单阻断**：任何一行坏 → 整张源单一行不导（按单据号判，不按客户）
  - 三类流水一次写齐：每行 1 条库存流水 + 整单 1 条应收 + 借贷平衡凭证
  - 幂等靠备注 `历史导入|源单号=XXX|来源=YYY`，重导自动跳过
  - 名称归一（全角半角/空格/尾标点）、Excel 日期序列号兜底、客户别名映射
- **回滚工具**：`scripts/shansong_import_rollback.py --only 系统单号 --commit`，只许撤「历史导入」单，连流水凭证一起删干净

### 12. 桌面版与打包
单文件 exe（`erp.spec`）、`data/` 目录不打包需 robocopy 随附、Word/PDF 打印导出（`erp_word.py`/`doc_export.py`）。

## 三、关键业务规则（改代码前必读）

1. **钱 ≠ 费率**：金额/合计/税额 `Numeric(…,2)`；单价/数量是"费率" `Numeric(14,4)` 最多 4 位不截断；合计=逐行金额累加。算术必须走 `app/core/money.py`，禁 `round()`。
2. **单据状态唯一权威** `app/core/doc_status.py`；**单号前缀唯一权威** `app/core/doc_no.py`（路由禁字面量前缀，`verify_doc_no_prefix.py` 静态守）。
3. **对外只给中文 400**，不用 422（422 的英文 errors 数组会直接弹给用户）。
4. 固定路由必须写在动态路由之前（曾 `PATCH /products/batch-category` 被吃掉变 422）。
5. `Update` schema 少声明字段 = 静默无效（pydantic 忽略未声明字段，200 却没改）。
6. 改路由文件后必须 curl 探接口（`ast.parse` 查不出丢失的装饰器）。
