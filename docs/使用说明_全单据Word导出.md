# 全单据 Word 导出 · 使用说明

> 给业务同事看的操作手册。不懂代码没关系，照着做就行。

---

## 一、这个功能是干什么的？

以前要把系统里的单据发给客户或供应商，只能**打印成 PDF**，或者截图贴到 Word 里重排一遍。

现在系统里的四种单据，可以**一键导出一份排好版的 Word 文件**（`.docx`）：

- 购销合同
- 报价单
- 采购入库单 / 采购订单
- 对账单

导出来的文件**可以直接盖章发给对方**，也能在 Word 里再改两句话——因为它是真正的 Word 文档，不是在图片上打字。

**它不改动系统里的任何数据。** 导出多少次都不会把单据改坏、不会生成流水、不会动库存。放心点。

---

## 二、功能入口在哪里？

一共四个地方，按钮都叫「**Word**」或「**导出 Word**」：

| 想导出的东西 | 去哪儿 | 按钮长什么样 |
| --- | --- | --- |
| **购销合同** | 销售管理 → **合同台账** | 列表里每一行的「**Word**」（打印按钮右边）；<br>打开「详情」后顶部还有「**导出 Word**」 |
| **报价单** | 销售管理 → **报价单** | 列表里每一行的「**Word**」（打印按钮右边） |
| **采购入库单 / 采购订单** | 采购管理 → **采购入库** | 列表里每一行的「**Word**」（打印按钮右边） |
| **对账单** | 销售管理 → **增强对账单** | 右上角工具条最右边「**导出 Word**」 |

> 「增强对账单」的按钮在**载入或生成一张对账单之后**才会亮。没载入单据时它是灰的——这是故意的，防止对着空白导出一个空文件。

---

## 三、怎么用（三步）

1. **找到单据**：进到上面表格里对应的页面。
2. **点按钮**：
   - 列表里的单据 → 点那一行的「**Word**」；
   - 对账单 → 先用「载入已存对账单」选一张（或点「生成草稿」生成一张），再点「**导出 Word**」。
3. **去"下载"文件夹拿文件**：浏览器会自动下载，文件名长这样：

```
购销合同-HT20261019001.docx
报价单-BJ202605150006.docx
采购入库单-CG20261018002.docx
对账单-DZ20261019001.docx
```

文件名就是「**单据类型-单据编号**」，一眼能认出是哪一单。

点完之后页面右上角会弹一句「已导出 xxx.docx」，看到这句就说明成功了。

## 四、导出的文件长什么样？

四种单据版式略有不同，但骨架是一样的，从上到下：

```
┌────────────────────────────────────────────┐
│            西安寨卡信息技术有限公司          │  ← 公司抬头（大号黑体，居中）
│   地址　电话：029-…　税号：9161…            │  ← 公司地址/电话/税号（小字，居中）
│ ────────────────────────────────────────── │  ← 一条横线
│                购 销 合 同                  │  ← 单据大标题
│                                            │
│ 合同编号：HT…    签订日期：2026-10-19  …    │  ← 编号 / 日期（左右分开）
│                                            │
│ ┌──────供方（甲方）──────┬──────需方（乙方）──────┐ │
│ │ 名称   …              │ 名称   …              │ │  ← 双方信息块（税号/法人/地址/
│ │ 税号   …              │ 税号   …              │ │     联系人/电话/开户行/账号）
│ │ …                     │ …                     │ │
│ └───────────────────────┴───────────────────────┘ │
│                                            │
│ 一、标的物清单                              │  ← 章节标题
│ ┌──┬────────┬──────┬──┬────┬─────┬──────┐ │
│ │序号│货物名称│规格型号│单位│数量│单价 │金额  │ │  ← 明细表（灰底表头 + 框线）
│ ├──┼────────┼──────┼──┼────┼─────┼──────┤ │
│ │ 1 │ …      │ …    │米 │4654│100.81│469169.74│ │
│ │ … │        │      │  │    │     │      │ │
│ ├──┴────────┴──────┴──┴────┴─────┼──────┤ │
│ │ 合计（人民币大写）：贰佰陆拾壹万…│¥2,617,568.02│ │  ← 合计：大写 + 小写
│ └──────────────────────────────────┴──────┘ │
│                                            │
│ 二、结算与开票   三、交货与验收             │  ← 条款区（只印有内容的项）
│ 四、质量、质保与违约责任   五、其他约定      │
│                                            │
│ ┌──────────────────┬──────────────────┐   │
│ │ 供方（甲方）（盖章）：│ 需方（乙方）（盖章）：│   │  ← 签字栏
│ │ 法定代表人或授权代表：│ 法定代表人或授权代表：│   │
│ │ 日期：　年　月　日   │ 日期：　年　月　日   │   │
│ └──────────────────┴──────────────────┘   │
│                                            │
│        西安寨卡信息技术有限公司   第 1 页 / 共 2 页 │  ← 页脚（页码会自动走）
└────────────────────────────────────────────┘
```

几个细节值得知道：

- **金额一定是"大写 + 小写"两个都给**。合同上只写小写不合规，所以合计行左边是中文大写、右边是数字。
- **明细超过一页时，第二页的表头会重复**（列名「序号/名称/数量…」还在），不用来回翻第一页对列。
- **页码是"第 X 页 / 共 Y 页"**，不是写死的数字，插页删页会自动变。
- **条款区只印有内容的项**。没填的条款不会留一堆空白标题占地方。
- **采购合同的签字栏左右会换过来**：采购时我方是"需方（甲方）"、对方是"供方（乙方）"，别让对方签错边。

## 五、四种单据各自印了什么

### 1. 购销合同

抬头、标题（合同名称）、合同编号、签订日期、签订地点、**供方/需方信息块**（名称、税号、法定代表人、地址、联系人、电话、开户行、账号）、标的物清单、合计大写+小写、结算与开票、交货与验收、质量质保与违约、其他约定、签字栏。

> 库里如果之前记过「金额大写」（比如 OCR 认出来的），会单独印一行「金额大写（库内记录）」跟系统算出来的大写并排放，方便核对。**两个不一致时以系统算的为准**，但要顺手查一下原来那个是怎么来的。

### 2. 报价单

抬头、标题「报 价 单」、报价单号、报价日期、报价有效期、**客户信息块 + 报价单位信息块**、明细表、合计大写+小写、商品数量合计、报价说明、签字栏（报价单位 / 客户确认）。

底部固定印一句「以上报价含税单价以人民币计；如有变动以双方另行确认的书面文件为准。」——这句是标准免责，别删。

### 3. 采购入库单 / 采购订单

**同一个版式，标题不一样**：

- 入库单（真的收货入库了）→ 标题「采 购 入 库 单」
- 采购订单（只是订货，还没到货）→ 标题「采 购 订 单」

内容：抬头、单号、开单日期、仓库、**供应商信息块 + 本单信息块**（业务员、付款方式、送货日期、备注）、明细表、合计大写+小写、结算行（应付/优惠/实付/本次欠款/累欠货款，只印有值的）、签字栏（仓库保管·收货人 / 供应商·送货人）、三联说明。

> 导出哪一版由单据本身决定，你在列表里看到的单号前缀也能分辨：`CG…` 是入库单、`CGD…` 是采购订单。

### 4. 对账单

抬头、标题「客户对账单（应收）」或「供应商对账单（应付）」、对账单号、账期、制单日期、**对账单位 + 我方信息块**、逐笔明细（业务日期、摘要、单据编号、合同金额、已开票、已收/已付、余额）、**汇总块**（期初余额、本期合同金额、本期已开票、本期未开票、本期已收/已付、期末余额、剩余未结）、本期合计大写、对账说明、签字栏。

底部固定印「请核对以上账目，确认无误后盖章回传；如有异议，请于收到本对账单后 5 个工作日内书面提出。」

## 六、遇到问题怎么办（防呆提示）

### Q1：点了按钮，什么也没发生？

先去看**浏览器的下载文件夹**（一般叫「下载」/ Downloads）。多数情况是文件已经下来了，只是浏览器没弹提示。

如果确实没有：

1. 看页面右上角有没有红色的失败提示，上面会写原因；
2. 检查公司电脑有没有装「下载拦截」类插件——有的话找 IT 放行；
3. 让管理员在浏览器里直接打开这个地址试一下：
   `http://127.0.0.1:8010/api/v1/exports/word/kinds`
   能看到一串文字（四种单据的清单），说明服务是好的。

### Q2：文件下载下来，打开说"文件已损坏"？

极少见，一般是下载被中断。**重新点一次**就好。如果每次都坏，记下单据编号报给管理员。

### Q3：公司抬头那一行显示"（公司抬头未设置，请到「系统设置 → 公司信息」补全）"

说明系统里**公司信息还没填**。去「系统设置 → 公司信息」把公司名称、地址、电话、税号、开户行、账号填上，再导出就正常了。

> 这是故意留的提示，不是报错——空着不写比写一句提示更糟，因为打印出来就成了一张没有抬头的纸。

### Q4：明细表里只有一行"（无明细）"

说明这张单据本身**没有明细行**（比如手工建了个空单）。回系统里把明细补上再导。

### Q5：文件名变成了一堆下划线，比如 `____-HT20261019001.docx`

这是**中文文件名在极少数环境里被降级**了（老版本浏览器 / 某些下载工具）。文件内容是好的，改个名字就行。

如果经常这样，换成 Chrome 或 Edge 再试。

### Q6：金额大写跟合同上写的不一样？

系统是按数字自动转成中文大写的（"贰佰陆拾壹万柒仟伍佰陆拾捌元零贰分"这种）。**只要小写金额对，大写就是对的**——如果和纸质合同上的大写对不上，那多半是纸质合同本身写错了，或者原合同金额改过。

### Q7：对账单的「导出 Word」是灰的，点不动

因为**还没载入单据**。先用右上角「载入已存对账单」选一张，或者点「生成草稿」生成一张，按钮就亮了。

### Q8：导出来的合同，签字栏左右两边跟我想要的反了

这是按**合同方向**自动排的：

- 销售合同（我们卖）→ 左边「供方（甲方）」= 我们，右边「需方（乙方）」= 客户
- 采购合同（我们买）→ 左边「供方（甲方）」= 供应商，右边「需方（乙方）」= 我们

如果确实反了，说明这张合同的「方向」选错了，去合同详情里改方向，再重新导出。

### Q9：导出会不会把单据改坏？

**不会。** 导出是纯"读"操作：不写数据库、不改状态、不生成流水、不动库存。

唯一的例外是你自己点了「保存」「审核」之类的按钮——那是另一回事。

### Q10：导出的文件能改吗？

能。它就是普通的 `.docx`，用 Word / WPS 打开随便改。**但改了只影响这一个文件，不影响系统里的数据**。要改系统里的，回系统里改再重新导出。

## 七、打印前自查清单

发给对方之前，扫一眼这五项：

- [ ] **公司抬头**是本公司名字（不是"公司抬头未设置…"）
- [ ] **单据编号**、**日期**是对的
- [ ] **对方单位名称**、**税号**没写错（这一项错了要重开）
- [ ] **明细条数**和金额加起来，跟你要的总额一致
- [ ] **签字栏**两边的人是对的（别让对方签到我方那栏）

都对了就可以盖章发出去。

## 八、管理员备注（技术向，业务同事可跳过）

- 后端：`app/services/word_export.py`（四个 `build_*` 生成函数）+ `app/api/v1/routes/erp_word.py`（接口）。
- 接口：
  - `GET /api/v1/exports/word/kinds` — 可导出的单据类型
  - `GET /api/v1/exports/word/{kind}/{doc_id}` — 下载 `.docx`
    - `kind` 取值：`contract` / `quotation` / `inbound` / `statement`
    - 加 `?as_json=true` 返回 base64 JSON（下载被插件拦截时用来排查）
- 前端统一入口：`frontend/src/lib/wordExport.js` 的 `exportWord(kind, docId, fallbackName)`。
- 依赖：`python-docx`（已在 `.venv` 里）。
- **改了后端代码必须重启程序才生效**（双击 `启动ERP.bat`），改完前端要 `npm run build`。
- 中文字体是**逐 run 单独设 `w:eastAsia`**，不是只设 `font.name` —— 否则 Word 里中文会掉回"等线"。这段逻辑在 `_cn_font()`，别简化。
